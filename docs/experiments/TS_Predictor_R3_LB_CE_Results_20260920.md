# R3 LB CE完整结果分析

日期：2026-09-20。仅分析服务器结果，不运行编码、不修改算法、宏或源工作簿。

## 1. 结论先行

**R3-1是本轮优先保留的候选；R3-2备用；R3-3/4不建议继续扩大正式测试。**

- R3-1：CE **−0.093288%**，中位数−0.082512%；去除PartyScene后仍−0.030671%。
  比R2-R、固定NoPred和directional的CE均值更好；高、中、低质量区间均值均改善。
  不是仅靠把作用压回Current获得接近零的结果。
- R3-2：CE **−0.078682%**，5/7序列改善，比R3-1覆盖稍广；但全局均值较差。
  两者差距小且不确定，不能证明全分量始终更优。按冻结规则同族只保留一组，优先R3-1。
- R3-3/4：CE分别 **−0.011663% / −0.014754%**。高质量收益只保留父方法约42%/46%，
  中位数为正，去除PartyScene后退化；历史保护没有带来可支持推广的净增量。
- **上述都是CE，不是BCE。** R3没有B或RA结果，不能宣布达到BCE −0.05/−0.08/−0.10%目标。
- 按此前“稳定BCE收益、RA无系统退化、复杂度可接受才Promising”的定义，整体正式评级仍为 **Weak**。
  R3-1是明显较有希望的晋级候选；R3-3/4相对于其新增保护机制及继续扩展的证据为 **Negative**，
  这不等于证明所有因果CG自适应都不可能有效。

表格pass与CSV一致只证明数值/状态记录一致，**不能独立认证远端宏、二进制、实际半帧数、配置或解码hash**。
目录没有远端运行metadata、CG活动统计或编码日志；本次不根据本地程序推断远端状态。

### 主指标

逐序列各分量用总码率与对应PSNR独立计算四点PCHIP BD-rate，再：

\[
BD_{611}=\frac{6BD_Y+BD_U+BD_V}{8}.
\]

CE是七序列等权：

\[
BD_{CE}=\frac{4BD_C+3BD_E}{7},
\]

不是 `(C+E)/2`。BCE才是十二序列等权。本报告负值表示改善，单位%或明确标注的百分点。
PCHIP与工作簿VBA公式的独立实现核对，全部新/对照曲线最大差约 **4.24×10⁻¹³个百分点**；
没有直接信任可能过期的Excel公式缓存，也没有改成先加权PSNR。

旧R2-R/N与固定NoPred/directional只使用完整实测CE曲线，无旧补点参与本次直接比较。
跨轮配置/版本可比性仍依赖远端记录；重复使用CE并非独立验证集。

## 9. 原始研究问题：本轮回答了什么、没有回答什么

1. 在本CE集合和6:1:1口径下，局部保护存在超过固定Current的闭环改进证据，但并非对所有内容和配置都成立。
2. **R3-1/2是利用因果邻域逐系数选择，不是只用之前CG选择整个当前CG。**
   它们的成功不能作为原始“跨CG历史可预测性”的成功证明。
3. 真正纯历史CG模式R3-3/4仍缺乏净增量，历史有利不代表当前CG有利。
4. 没有CG级Oracle、模式转移、TU尺寸、CG数和活动数据，不能计算η、persistence或Gain vs N_CG。
   Class C/E差别混合了内容与分辨率，不等于TU尺寸效应；不能默认尺寸为8×8。
5. 此轮是闭环编码，predictor会改变q和TS选择，避免只在anchor最终TS固定q上评价的主要局限。
   若以后使用各工具最终TS日志解释机制，这些日志依旧是条件样本，不能冒充无偏全搜索统计。
6. 表内编码/解码时间缺硬件、负载、并行度及重复测量信息，不据绝对时间判断工具开销。
