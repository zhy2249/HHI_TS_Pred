## 3. 已完成的原生局部测试

八个R11模式分别通过：262,144项中性context长度检查、40,000项旧score等价检查，
160个原生TU、1,491个CG、23,436个未来系数污染位置。
覆盖方形/矩形2～32、YUV、Rice1～8、低regular预算、BDPCM、全零CG及幅值边界。
这是人工构造覆盖，不是“本次CTC观察到所有这些尺寸”。

每CG比较私有回放和原生CABAC estimator的fractional bits、预算、出口概率状态；
真实入口状态不被修改，局部Writer/Reader恢复系数一致。
独立参考使用旧公开专家接口生成A/B/C，重新构造原生scan历史集合并手写选择公式；
只有测试参考穷举已知prefix，生产代码只枚举24个几何偏移。

还检查q编辑、前缀CG清零、恢复原q、复制分支的概率快照切换/恢复、
V0/V3/V4有序前缀、R11内部mode0逐动作等于R10-3，模式1有证据区不变、模式2唯一CI赢家不变。
模式4/8各实际访问47,819个跨CG参考目标（含各测试分支重复访问），不是未触达分支的空验证。
模式5/6分别触达394/5,285次“ABC动作相同但D不同”；第四专家未被前三专家快捷返回跳过。

## 4. 既有两帧合成短测

证据`runs/ts_r11_smoke/validation.json`，人工64×64、2帧、固定种子。
case为AI22、AI0（最大TS允许到32）、LB22、RA37、禁TS及BDPCM配置。
共290个任务通过，不是290条CTC序列。

- 78个旧模式在AI22相对保留的R10二进制逐字节相同。
- 八组R11禁TS时与Current相同。
- R3-1/R9-9/R10-3和八组R11，六个case的观察开关不改变码流。
- 5,297条最终CG系数/动作/证据/预算trace在Writer与Reader之间一致。
- 解码MD5检查通过；未检测正式BD-rate。

| R11_MODE | 相对R10-3出现码流差异的合成case |
|---|---|
| 1 | AI22、AI0、LB22、RA37、BDPCM配置 |
| 2 | AI0 |
| 3 | AI0、LB22、RA37 |
| 4 | AI0、LB22、RA37、BDPCM配置 |
| 5 | **未观察到** |
| 6 | AI0 |
| 7 | AI22、AI0、LB22、RA37、BDPCM配置 |
| 8 | AI22、AI0、LB22、RA37、BDPCM配置 |

BDPCM配置仍包含普通TS块，差异不是BDPCM映射被修改。
不能把AI0的活动等同于正式CTC QP的活动，更不能等同于收益。

R11-5进一步核验：R10-3的AI0最终系数轨迹有3,521个regular观察位置，
模式5的shadow选中D共7次、相对基础动作不同4次、实际remap不同0次。
其它四个含TS的case在该轨迹上也没有模式5的remap差异。
这支持“D确实参与竞争，但本样本尚无实际映射活动”，不支持“未启用宏”，
也不证明所有真实内容上冗余。保持预设公式，先做真实内容预检，不为了制造活动调参。

## 5. 观察日志与局限

活动脚本解析135份关联编码日志，共306,167条分层，日志66,207,904字节。
其中含统计关闭/无TS任务；无观察记录不自动解释为零活动。
每个最终人口观察八个模式，不能把八份人口相加；三条旧轨迹与新模式闭环轨迹分开。
这些合成任务沿用输入模板的sequence字段，**不是BasketballDrill等真实视频结果**。

目标CI/CF/实际cutoff-CF和regret来自已定q，只用于观察，不进入公共选择。
实际路径CF使用冻结概率及真实cutoff，没有假想分支上下文/预算传播，不是完整CABAC反事实。
当前实现的高维分层/八份观察仍可能较大，正式CE默认关闭统计；不直接全CTC开观察。
原始日志和构建产物保留本地，不上传Git。

未测：真实内容BD-rate、CTC速度/内存、R11-5真实活动、2/6正式QP活动、跨类别泛化，
以及本轮master-OFF码流一致性。无缓存第一版不作生产性能承诺。
后续固定内容短测通过后才进入八组CE；B按最新计划门槛及哨兵流程人工启动。
