# TS predictor 跨轮多维分析

日期：2026-09-19。范围：历史固定 predictor、revision1 条件/历史自适应、R2，以及旧反事实统计的限定性解释。
**本次只分析，不修改编码算法，不启动编码，不改原工作簿。**

## 1. 结论摘要

不能把目前的情况概括为“所有预测公式都不够准确”。更有证据支持的描述是：

1. **存在明显的内容、质量区间、分量与配置交互；某些平均接近零的方法，其局部收益和损失都不小。**
2. 高质量区间的改善在多个实验中反复出现；R2-N 在该区间七序列全改善，但低质量区间损失抵消收益。
3. 历史选择并未稳定优于固定候选；它既能改善固定方案，也能比两个固定端点都差。更复杂评分没有稳定增量证明。
4. 色度的影响不可忽略，但“U 全面失败”并不准确；部分平均损失集中在少数序列/质量区间。
5. 现有 BCE 正式结果仍未达到 −0.05%；不能由 CE 或旧固定模式的 B 推算 R2 已达标。

整体判断仍为 **Weak**。R2-R 是较值得保留的局部成本方法，R2-N 是有明确区间结构的低复杂度自适应对照；
这不是认定两者已达到 Promising，也不能据此给它们设计序列专用开关。

## 2. 口径与证据边界

- 正式 anchor 始终为 Current。每序列 Y/U/V 各算 PCHIP BD-rate，再 `(6Y+U+V)/8`；全文负值为收益。
- CE 是 C4+E3 的七序列等权，BCE 是 B5+C4+E3 的十二序列等权，不是 class 等权。
- 固定模式：NoPred/directional 有 LB BCE 和 RA CD，gradient 有 LB CE 和 RA CD。
- revision1：五组 CE 共130实测点；9个QP22缺失、另缺1个QP27。
- R2：四组 CE 共111实测点；只缺 R2-F PartyScene QP22。
- 沿用此前用户授权，只在分析中以 Current 暂代缺失QP22，不补QP27。q32_ewma 的 PartyScene 整条曲线不可计算。
- 合计读取12个实验工作簿、461个实测点；10个点用anchor暂代，1个点不填补。
  共117条可计算曲线，其中9条含补点；另一个填补点属于仍缺QP27、最终被排除的曲线。
- 新脚本从原始工作簿重新计算，117条曲线的各分量及加权PCHIP与既有报告输出完全一致；Reference全部相同。
- 各轮相同序列不是独立重复实验。外部表格不能认证远端软件、实际帧数、环境或模式身份；不据本地程序推断远端运行情况。

`*` 表示均值中含anchor补点；`†` 表示只有六序列，不能与完整CE均值直接排名。
缺失值填补不是保守下界，相关排序暂定。

### 4.1 BQMall：共同弱点，但不是所有质量区间都差

12个实际实现的方法在BQMall整曲线上全部退化（其中旧A2/A3含补点）。
然而固定NoPred、directional、q32及R2-R/N/F在QP22–27对应区间均有收益。
R2-N该序列的三个区间依次为：高质量−0.0466%、中间+0.6058%、低质量+0.6112%。
因此应研究中低质量损失，不能归纳为“该内容永远不适合改变predictor”。

### 4.2 BasketballDrill 与 FourPeople：方法具有互补表现

BasketballDrill更支持固定directional与Current/NoPred历史选择；R2-N/F在三个质量区间都改善。
FourPeople则偏向局部模板方法：R2-R在三个区间都改善，而R2-F整曲线退化。
这说明方法的作用不只是按同一尺度整体变强/变弱；**仍不能由序列级互补推断CG历史能够正确选择两者。**

### 4.3 PartyScene：强收益案例，不宜再作为主要调参依据

多数方法已在该序列反复取得较强收益，固定NoPred −0.3598%与R2-N −0.3544%接近。
此处不能体现历史选择的额外优势。它又是多组均值的主要支撑，应与其他六序列并列检查，避免反复围绕它优化。
R2-F缺失该序列QP22，−0.1491%不能用于确认其相对其他方法的真实差距。

### 4.4 Johnny：需要保留旧方向预测作为机制对照

固定directional为−0.1108%，R2四组却全部退化。更复杂的候选并没有包含一个对所有内容都更强的预测。
固定NoPred在Johnny高质量区间+0.4797%、低质量−0.4865%，趋势还与许多其他序列相反。
所以“所有预测方法只在低QP启用”并不是现有数据支持的通用规律。

## 5. 质量区间：本次最重要的新分解

下面在**原四点PCHIP曲线**上积分，以anchor QP32、QP27的分量PSNR划分三个区间。
每分量使用自身公共质量范围；先分量BD再6:1:1。不作两点拟合，不外推。
区间数值不能简单算术平均恢复整曲线结果，更不是“某个QP编码任务的BD-rate”。

| 方法 | 高质量：QP22–27对应 | 中间：QP27–32对应 | 低质量：QP32–37对应 | 高质量改善数 |
|---|---:|---:|---:|---:|
| 固定NoPred | −0.09881% | −0.04552% | −0.01577% | 5/7 |
| 固定directional | −0.19634% | −0.04394% | +0.15076% | 7/7 |
| N1 q32 | −0.13541% | +0.08883% | +0.18082% | 6/7 |
| N2 conf2 | −0.14298% | +0.06499% | +0.19190% | 5/7 |
| R2-M | −0.02531% | +0.09913% | +0.13066% | 5/7 |
| R2-R | −0.10002% | −0.02327% | +0.05171% | 6/7 |
| R2-N | **−0.16225%** | −0.01732% | **+0.15200%** | **7/7** |
| R2-F | −0.12922%* | −0.02331%* | +0.10361%* | 5/7* |

由此应修正单看总平均的认识：

1. R2-N并非“基本没有作用”，而是两端的作用方向相反。它的高质量区间甚至比固定NoPred更有一致性。
2. R2-R的总平均更好，部分原因是其低质量代价小于R2-N，不是每个区间都更好。
3. q32/conf2没有消除旧directional的低质量风险，反而中间区间也变差。
4. 不能据此宣称再次加QP门控就能成功：旧nominal QP拼接曾给出CE −0.0993%、BCE −0.0703%，
   但真实CU-QP<=32的q32完整CE为+0.0304%。运行级名义QP、实际CU QP与曲线上某段质量范围不是同一变量。
5. q32的QP37表格点全部等于anchor，也不意味着整个QP32–37区间等于anchor；QP32点及插值斜率仍会影响该区间。

这里是探索性诊断，已经使用测试结果；未来若据此立规则，需要预先冻结，并用未用于选规则的条件验证。

## 6. 分量：不仅是平均U偏大

| 固定NoPred | −0.03768 | −0.00647 | −0.01256 | −0.05672% |
| 固定directional | −0.01174 | +0.00623 | −0.03111 | −0.03662% |
| R2-M | +0.03439 | +0.05306 | −0.01886 | +0.06859% |
| R2-R | −0.02981 | +0.04947 | −0.05335 | −0.03369% |
| R2-N | −0.01924 | +0.02229 | −0.01468 | −0.01164% |
| R2-F* | +0.00051 | +0.00352 | −0.00843 | −0.00439% |

### 6.1 U损失的集中性

| R2方法 | U退化序列数 | CE U均值 | 去除KristenAndSara后的U均值 |
|---|---:|---:|---:|
| M | 5/7 | +0.42449% | +0.03337% |
| R | 5/7 | +0.39577% | +0.11520% |
| N | 3/7 | +0.17830% | −0.15700% |
| F* | 3/7 | +0.02818% | −0.24281%* |

因此不能说R2-N/F的U在多数内容上都变差。KristenAndSara的U是特别值得定位的失败点：
R2四组U BD-rate分别+2.7712%、+2.0792%、+2.1901%、+1.6542%。
在其QP32，U PSNR相对anchor分别下降0.1297、0.0809、0.1100、0.1013 dB；这不是仅由表格最后一位造成的现象。
但不能凭这些表格把原因锁定为“U predictor本身错误”，还可能含总码率、量化、划分、参考重建等反馈。

### 6.2 加权负值不保证亮度也改善

FourPeople的R2-R：加权−0.2041%，但Y为+0.0423%，主要由U/V改善提供收益。
R2-N：加权约−0.0033%，Y却为+0.2062%，基本由色度补偿。
R2-F：Y约+0.2377%，最终加权仍+0.1043%。
相反BasketballDrill的R2-N/F，Y本身分别约−0.2546%/−0.2909%，是较明确的亮度收益案例。

这些加权收益按约定都是有效指标，只是作用机制不同。不能把某分量替换成anchor数值，拼装“关闭该分量后的收益”；
真正luma-only/chroma限制必须另做闭环实验，且不是当前已验证方案。

## 7. 自适应是否比固定方案有效？

这里做实际RD曲线直接配对积分，不以两个对Current的BD-rate相减冒充直接BD-rate。
Current仍为所有正式结论的anchor；以下只评估新增选择器的增量。

| 比较：后者相对前者 | 集合 | 直接加权BD-rate | 后者改善数 |
|---|---|---:|---:|
| NoPred → R2-N | 完整CE7 | +0.04468% | 2/7 |
| NoPred → R2-F | 不含PartyScene的实测6序列 | +0.02563% | 3/6 |
| NoPred → R2-R | 完整CE7 | +0.02376% | 2/7 |
| directional → R2-R | 完整CE7 | +0.00363% | 2/7 |
| R2-M → R2-R | 完整CE7 | −0.10094% | 4/7 |
| R2-N → R2-F | 不含PartyScene的实测6序列 | −0.02478% | 3/6 |
| directional → q32 | 完整CE7 | +0.06716% | 1/7 |
| directional → conf2 | 完整CE7 | +0.07966% | 1/7 |

这些比较支持的判断：

- 风险成本准则较多数规则有改进价值，但尚未稳定胜过已有简单固定模式。
- q32/conf2两个门控在多数序列上比无条件directional更差，不是“保护稍弱”这么简单。
- R2-F相对R2-N在共同实测六序列有所改善，但只赢3/6；原配对bootstrap区间跨0。
  不能说复杂评分完全无效，也不能认为其开销已有收益支撑。
- 将旧A2的directional候选换成NoPred后，BasketballDrill显著改善，但Johnny/KristenAndSara反而变差；
  候选替换不是逐内容全面升级。旧A2缺点较多，完整CE配对暂估不可作确定排序。

### 自适应并不天然处于两个固定端点之间

R2-N在BasketballDrill上比Current和固定NoPred都好；在FourPeople也略优于两者。
但在BQMall、Johnny、KristenAndSara上，R2-N与R2-F都比Current和固定NoPred更差，且这三条曲线均完整实测。
这不是数据矛盾：当前CG的选择可能错误，并会改变后续上下文、RDOQ、TS入选和参考重建。
因此不能认为“在两者之间切换，只可能把两者的优点取出来”，也不能把固定两端当作自适应结果的数学上下界。

## 8. 分辨率、Class B与RA：推广证据弱

### LB Class B

| 固定方法 | B平均 | 去掉Cactus后的B均值 | BCE平均 |
|---|---:|---:|---:|
| NoPred | −0.02068% | +0.03139% | −0.04170% |
| directional | −0.03443% | +0.03354% | −0.03571% |

Cactus加权分别−0.2290%/−0.3063%，但Y仅−0.00688%/−0.03883%；收益主要来自色度。
所以不能用B的负平均宣称高分辨率亮度普遍改善，也不能推断R2会复现Cactus收益。
R2-R若保持当前CE，B均值还需≤−0.07283%才能使BCE达到−0.05%；这比旧两个固定模式已测B均值更负。
这只是达标所需条件，不是B预测。

### RA配置

固定NoPred/directional的RA CD分别−0.00831%/+0.00317%；去掉BQSquare后分别+0.02133%/+0.03951%。
RA NoPred的Y均值+0.00971%，小幅加权收益主要由U提供。
PartyScene的LB NoPred −0.3598%，RA却仅−0.0142%；directional在LB −0.2961%，RA为+0.0203%。
同一内容换配置后方向/幅度会改变，不能仅按纹理或“屏幕/自然内容”标签解释。
RA帧数等外部来源尚未独立核实，此处仅比较所收表格，不将差异全部归因于预测结构。

C、E、B同时改变分辨率、内容和配置可用性；这些不是只改变分辨率的控制实验。
也不能由class差异推断TU尺寸效应，后者需要实际TU/CG统计。

## 9. 同QP数据、插值与不确定性

- R2-N在QP37，七序列平均码率变化约−0.00007%，但Y/U/V平均PSNR分别下降0.00609/0.00450/0.00673 dB。
  只看码率会误认为基本无变化，RD效果并非如此。
- 本轮111个实测点仅2个点四个表格数值均与Current相同；这不支持“实验全部没生效”，
  但也不是远端模式身份或bit-exact证明。
- R2四组CE序列bootstrap区间均跨0；实验2例如约[−0.1670%,+0.0996%]。
  CI描述内容变异，不是重复编码噪声；跨0不证明等价，负平均也不证明普适。
- R2-F补点CE −0.00439%，换cubic约+0.00578%；假设缺失QP22的PSNR保持anchor，仅码率±0.5%，
  CE可变为−0.01551%或+0.00668%。这是假设敏感性，不是置信区间或真实范围。
- 12组在同7条CE上反复查看、设计和比较，存在选择最优方法后的乐观偏差。
  新分段发现是探索性线索，不是独立确认；不要继续用这7条序列反复寻找最有利阈值。
- 目前结果是确定性编码数值，不能把小幅损失随意称为随机噪声；需要明确工程量级、内容稳定性和计算敏感性。

## 10. 与最初固定q反事实统计如何衔接

旧16帧AI/LB反事实实验：85.60% CG各候选成本相同，Current样本上的NoPred总体TSRC成本增加约0.96%；
Oracle约有1.62%的TSRC内空间，历史recency捕获率为负。只有1个CG的TU约15.92%，并不是所有失败都能归因于单CG。
历史正收益证据出现过晚，也是旧样本的一个明确限制。

而真实闭环固定NoPred的LB BCE为−0.04170%。这说明不能直接拿旧固定q排名作为闭环工具排名，
但**不能把两者差值全部归因于选择偏差**：旧实验普通LB/AI与后来的LBeu High配置、帧长也不同，分母更不同。

旧结果可提出“有效历史稀疏、启动过晚、代价不对称”等待检验机制；不能直接给本轮R2套用85.60%、η或TU分布。
当前只有服务器RD表，不能新增以下结论：

- 实际TS使用率、被改变的coefficient数或NoPred选择率；
- 各真实W×H、CG数、CG位置和有效历史长度的收益；
- 本轮Oracle mode persistence及capture ratio；
- 远端编码/解码复杂度或某内部机制已经被证实。

## 11. 后续优先级：先定位失效条件，不继续堆公式

1. **先补齐R2-F PartyScene QP22**。旧A1/A2/A3若参与最终排名，也需补齐各自缺点。
2. 保留R2-R与R2-N两类不同机制的对照。前者低质量代价较小，后者高质量一致性更好；不据内容名称拼装选择规则。
3. 下一次短帧诊断重点看BQMall、KristenAndSara中低质量损失，同时保留BasketballDrill/FourPeople成功或互补案例，
   不只挑成功样本。按实际CU QP、component、W×H、CG index及有效remapping位置交叉统计。
4. 关注“发生变化的次数”和“变化后的代价”分开：p=0/1均为identity，predictor改变未必改变语法；
   评分变复杂或切换增多也不等于正确。记录有效历史、score margin、mapped变化与最终入选情况。
5. 不同闭环模式的TU划分会不同，不能把坐标相同的CG直接当作一一配对样本。
   最终TS统计用于描述机制，整序列闭环RD仍是避免原先选择偏差的主效果评价。
6. 如果提出QP/分量保护，只冻结少量有机制依据的规则，先作真实闭环验证；不要再把离线RD点拼接收益作为算法收益。
7. 暂不扩大四组B测试。按原稳定性准入仍无明确通过者；若选择R2-R作探索性B验证，应明确它是探索而非原门槛已通过。

**结论分层**：gradient/R2-M和完整N1/N2在当前CE整体证据偏Negative；R2-R/N/F及固定NoPred/directional为Weak。
高质量区间的结构是值得保留的研究线索，但算法整体尚未有足够证据评为Promising。
