## 2. 保留的算法与矩阵

候选、n<3回Current、KeepHit损失、rho=21/2、168整数尺度、实际remapping及原量化搜索沿用v3。
`n`仍是五邻域中非零位置数，重复幅值不合并为一个支持；权重0不删除远邻候选。

对每个候选缓存近组/远组损失 `N(p), F(p)`，当前档按 `K*N(p)+r*F(p)`选唯一p。
各档评分只用于**各自选择p**，不比较不同r的原始分数大小。
当前局部量化q确定后，用未乘168的 `C(remap(abs(q),p_r))`评估各档可实现赢家，
按 `(cost, 距离当前r, 优先较大r)`产生方向；不对固定q再计算一次KeepHit机会收益。

- NONE：`r <- clip(r+d,0,K)`。
- PAIR2：`s <- clip(int(s)+d,0,2K+1)`，输出`r=s>>1`；先转有符号再加减，避免uint8下溢。
- E/H/Z初态及PAIR2低位相位严格按v3。无资格、中性事件保留完整状态，不清半档、不存pending。
- 每TU/分量/试编码重新初始化；不跨TU，不增加模式比特。

现行15组方法及运行名不变，公开编号压缩为1..15。阶段A队列为7/1/10/8/9/2/11，阶段B为3/4/5/6/12/13/14/15。
旧TARGET2/DIR2运行名继续拒绝；旧非连续编号日志必须按旧身份与runtime解读，不能直接套新号。
PAIR2不是“每次变权必须连续确认两次”；例如s=3→4→3对应r=1→2→1。

## 3. 接入前必须明确的目标范围

在每个`CoeffCodingContext`构造时，依据双方已知信息冻结：

```text
targetActive = R14被选择
               && 当前分量为Transform Skip
               && TSRC未禁用
               && BDPCM == NONE
```

非目标路径保持Current局部行为，不评分、不学习。此项落实原设计“非目标不变”，不是新增门限或实验。
原因是Writer/Reader的TSRC入口明确检查`!m_tsResidualCodingDisabledFlag`，
而`QuantRDOQ::quant()`本身只按TS/RDOQ分流；`DepQuant::quant()`在DQ关闭时仍可能回落到后者。
只检查全局R14 mode不足以排除TSRC-disabled的量化路径。

**不能用encoder-only的RDOQ开关限制最终隐式规则。** 小尺寸、lossless或RDOQ关闭时可能跳过TS-RDOQ，
但只要最终仍使用目标TSRC路径，Writer/Reader仍须按R14工作。相反，BDPCM单独排除。
普通TS纯bypass不实际remap，但仍学习：原allowUp在预算分支之前依赖p。

固定r=K/K/2对R13的等价声明限定在相同目标路径、H/Rice/range与输入下；
TSRC-disabled等非目标回归另对Current，不扩大为未经检查的全工具等价声明。

## 4. 生产接入设计：prepare不变状态，commit只做一次

以下接口和新文件名均为**拟实施**，不是已经存在的API。

### 4.1 公共纯函数与TU私有状态

拟新增`TsR14Prediction.h`，复用`r13CachedLoss168()`和真实`syntaxCost()`，不复制一套可能漂移的损失表。
相同幅值可共用C(m)/必要C(m+1)，但必须分别保留近组和远组的出现次数，不能沿用R13单一合并权重丢掉组别。
所有损失、N/F及乘加为int64；边界幅值先扩宽取绝对值，C(a+1)仅在存在大于a的赢家时按需查询。

建议分开三个操作：

1. `prepareR14(scanPos, coeff)`：只读因果五邻域和入口状态，生成各档赢家及当前action；不读当前目标值，不更新状态。
2. `commitR14(decision, finalMagnitude)`：有资格时只推进一次微状态；不再次评分或执行量化。无资格/零保持。
3. `snapshot/restore`：复制完整微状态；不受学习步长±1限制。缓存附属于本次trial/CG，不能跨回滚复用。

状态置于`CoeffCodingContext`的独立R14成员，不能借用旧`m_tsState`/`m_tsRecentMargin`/虚拟CABAC预算。
decision临时保存n、近/远有效性、p_r与入口r；无需保存原像素、源残差、当前round或lambda。
固定7/8/9（旧19/20/21）只计算指定档，不做无用全档反馈；观察开启时的额外诊断不得改变这条动作路径。

将来如合并局部编辑，须从最早受影响处重放，不能继续复用旧p缓存。

### 4.3 Writer和Reader为什么可以同步

Writer虽然持有整个最终q数组，预遍历每个位置只允许读取已完成的五邻域。
每CG先从入口状态产生p序列并推进一次，真实三遍语法使用缓存，不在remap lambda中学习。
该过程必须同时用于真正Writer和`isEncoding()==false`的fractional estimator，只有观察计数受isEncoding限制。
纯bypass返回原幅值，不能误用regular映射缓存；全零CG保持入口状态。

Reader第一、二遍只有映射后的部分幅值，不能用它们更新状态。第三遍完整remainder可得后，
用之前位置已恢复的真实邻居计算p；regular非零位置先反映射，再commit。cutoff=0仍commit，但不反映射。
当前规则只看幅值，符号在第三遍末尾统一恢复不影响学习。
significance/普通TS gt1上下文依赖邻居非零性，sign上下文依赖符号，并不要求第一遍提前知道R14状态。

`TsRateReplay.h`现有三遍回放会重复调用predict；**不能直接接入带更新副作用的R14回调**。
主算法无需CABAC回放，也不加入`needsTsRateContext()`。如观察需复用回放，从CG入口完整状态生成p缓存，
再在独立副本只读回放，不能从CG出口状态重新计算该CG。

## 6. 必要观察：反馈是否帮助下一位置

拟采用`TS_R14_STATS=0`、`TS_R14_TRACE=0`默认关闭；有界trace沿用detail limit/POC过滤思路。
不开新默认逐系数文本，不把算法必要状态更新绑在统计开关上。

区分四层活动：微状态变化、实际权重变化、选择p变化、实际语法映射变化。
若需量化allowUp活动，只能在RDOQ侧观察原round/min/up，标为trial人口；不能从最终Writer日志反推实际搜索次数。
最终Writer统计同一最终位置一次，不把3/5个网格观察分支相加当系数人口。

建议聚合字段：

- 身份及维度：mode、POC、实际CU QP、Y/U/V、W×H、intra/inter、CG数、CG索引及目标/BDPCM/实际cutoff。
- n、近/远非零位置数、有效反馈数；零/n<3/缺近组/缺远组/非目标分别计原因。
- s/r驻留、方向、相位变化但r不变、r改变、正反切换、各档赢家是否相同、反馈成本平局。
- 每TU有效反馈总数、首次变权前的有效事件数、变权后剩余有效位置、从未变权/从未变p的TU数。
- RDOQ的CG回滚仅在独立trial诊断中记录；最终Writer不能观察被丢弃CG的回滚次数。

**新增一项评价，不改变算法：下一有效位置的同轨迹收益。** 设上一个有效反馈事件更新前后输出为
`r_before`、`r_after`，在下一个有效位置j使用其相同H_j和最终a_j计算：

\[
g_{next}=C(f(a_j,p_j(r_{before})))-C(f(a_j,p_j(r_{after}))).
\]

状态更新只发生在有效事件，故两事件之间无资格位置不推进状态；同一位置不使用自己的反馈选择p。
有效事件包括满足资格但d=0的中性事件。分别统计正/零/负、均值及样本数；
PAIR2只变相位但r不变时g_next必为0，应单列而不是删除。

**g_next主表仅来自最终Writer，首版不在RDOQ trial中累计该指标。** 最终全零CG不产生有效事件，
但不清除前一有效事件的待配对记录；正常CG边界可在同一TU内继续配对，并标明跨CG。
TU结束时没有下一事件则标为未配对，不补零。保存上一次r对仅为默认关闭的观察字段，不是算法的pending目标/方向。
若将来增加trial版g_next，必须单列人口，并在CG入口保存观察快照、CG内缓冲或标注keep/zero；
清除待配对记录不能撤销已经累积的废弃CG内观察，不得将其混入最终Writer统计。

当前a上选r*的即时收益大部分来自最小化定义，不能证明历史可预测；走一个中间档的代价还可能上升。
g_next比即时收益更能检查时序价值，但仍是已受当前方法影响、最终选中TS的固定q条件统计，
**不是无偏反事实RD、真实CABAC节省或未选TS块的总体评价**。最终依据仍是独立闭环编码。

R14是系数级学习：**单CG TU也可能有历史**。沿实际W×H和有效反馈位置数分析，不能沿用
最初CG级方案“一个CG无自适应机会”的判据；不过TU前缀、稀疏区域及学习太晚仍可能使其无实际空间。
