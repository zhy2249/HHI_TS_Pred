## v3：仅方向反馈，直接逐级与双状态逐级

用户取消同目标确认，并提出以每两个内部状态对应一档权重代替独立缓冲。现行独立参考仅保留NONE与PAIR2，不再提供TARGET2或DIR2接口。

- NONE：一个状态表示实际远权，按反馈方向移动一档。
- PAIR2：s范围0..2K+1，r=s>>1；每个已确定系数最多更新s一次±1，实际r不跨档跳变。
- K=4映射0/1→0、2/3→1、4/5→2、6/7→3、8/9→4；K=2使用0..5。
- 不存pending目标或方向。中性反馈及无资格事件均保持完整状态，不清除半档相位。
- PAIR2不是严格同方向两次确认：3→4→3的状态变化对应权重1→2→1，两次均可单次跨边界。
- E初态s=2K+1，H初态s=K，Z初态s=0；H固定为该权重的低位状态，不额外增加相位实验。
- 全局目标及tie未变，反馈目标只用于产生本次方向；不把当前目标保存到下一系数，也不把目标搜索缩为相邻档。
- CG清零恢复完整微状态，包括最低位；初始化、回滚和试编码恢复不是学习转移，不施加±1限幅。

### 检查范围

1. D/U对c=1..256的独立有理数积分，共512项，含饱和与线性尾部。
2. 五邻域0..4穷举3125种，n>=3的2944种在G2/G4的3+5档共23552个赢家，与独立无缓存评分一致。
3. G2/G4、NONE/PAIR2的全部内部状态，对所有目标和无资格事件共126项。检查独立显式状态标签参考、微状态步长、权重步长、边界、中性保持。
4. 12种网格/更新/初态组合各1000个合成反馈，总计12000项。检查目标成本与tie、合法状态、单步及抽象CG回滚。
5. 两更新方式、三初态、各1000步的G2与等比例稀疏网格K=4、r={0,2,4}表示等价，共6000步。微状态是合法档位索引，不是稀疏网格的绝对权重；此测试不声称完整五档G4与G2相同。
6. 21个显式案例包括每档两个状态、全部初始相位、双向逐级路径、边界反向一次跨档、目标不同但方向相同、中性保留半档、CG恢复最低位、旧R13活动样例、第三候选反例、中间档不保证反馈成本下降，以及退役更新规则拒绝。
