## 统一计算口径

## 对 R8 的含义

1. 更细评分对原 Raw 有改善，但同样评分加旧 guard 反而退化；与“更准 rate 一定更好 RD”不符。支持重新做评分×规则配对，不证明 guard 普遍有害。
2. R7-1 的 Y 均值、中位数、改善序列数与加权总均值给出不同排序；保留全 YUV 主组，不能直接把 UV predictor 判为有害。
3. PartyScene、Johnny 与 KristenAndSara 的相反变化支持研究分布误差和候选覆盖，不支持按序列名开关。
4. 现有 R7 没有在 CE 总均值上替代 R3-1 的依据；评级 **Weak（相对 R3 的增量）**。R8 方案尚无结果，不提前评级 Promising。
