## 3. 冻结的输入、候选和统一评分

### 3.1 因果范围

位置i使用已有五邻域 `H=(L,U,D,LL,UU)`，边界、扫描及可用mask沿用当前正确实现。每个值是已恢复的量化幅值，不含符号。

`n`是有效非零位置数，重复值仍各算一个位置。新算法在`n<3`时直接沿用Current，不继续多级搜索。此门槛不随候选数量或前缀长度变化。

除两个空间消融，全部权重为11111；空间消融固定22111。零样本不计入静态非零幅值评分。

同值合并为`W(v)=sum_j w_j*1(H_j=v)`，但不能删掉重复支持。所有新选择只能使用H、已知Rice／动态范围与固定配置；禁止读取当前a、未来q、源残差、epsilon、真实回放费用、文件来源、序列名或绝对坐标。

### 3.2 正幅值池与固定优先级

正幅值池 `V={1}∪{H_j:H_j>0}`，最多6个不同值。不加入当前真实a、不外推、不增加历史幅值。

Current幅值 `c=max(L,U)`。固定候选优先顺序π为：若c>1则先c，然后1，再其余正幅值升序；否则先1，再其余正幅值升序。所有轮次使用同一个π，仅排除已选择的值。

0只表示恒等／不映射动作，**不是正幅值候选**。单值映射1与恒等同义，但1在多目标搜索中必须保留，不能沿用单值阶段的0/1归并而将它永久删除。

### 3.3 唯一主评分

`S_w(P)=sum_{v>0} W(v)*C(f_P(v))`，C逐字复用基线`syntaxCost(level,rice,range)`及其Rice尾部，不重新写一个近似版。

低等级示例：C(1)=1，C(2)=C(3)=3，C(4)=C(5)=4，C(6)=C(7)=5。

分数不再乘168，不使用rho、D/U查表或命中折扣。不做归一化也能选择最优，因为同一位置同组的权重和相同；跨权重的分数差只作归一化诊断，不直接比较。

用有符号64位保存总分、差值及累计惩罚。真实CABAC fractional units单列，每32768为1估计bit，不与此整数score混用。

## 4. 任意长度有序映射的完整定义

令 `P=(p1,...,pk)` 为不同正幅值组成的列表，k≤6。定义：

```
f_P(0) = 0
f_P(a) = j                         if a=p_j, j从1开始
f_P(a) = a+k-count(p_j<a)           otherwise, a>0
```

含义：依次把选中幅值放在1..k，剩余正幅值保持相对顺序；符号和零／非零意义不变。P为空是恒等映射。

逆映射：y=0返回0；1≤y≤k返回p_y；y>k先设t=y−k，再将P按数值升序遍历，对每个p执行`if t>=p: ++t`，后续判断使用已更新的t。返回t。

所有p均在该通道合法量化幅值范围内，整个映射必须在此有限范围内双射，不得溢出。中间算术扩宽后取绝对值。最大幅值的C(r+1)不允许越界访问。

### 4.1 搜索前缀不等于最终动作的最简表示

P=(1)、(1,2)与恒等同映射；P=(p,1)与单值p同映射。但是，附加一个自然占位符会冻结更长的低等级前缀，可能影响后续扩展。

**搜索中不能只因当前映射相同，就合并不同k或不同已选集合的状态。** 单路径算法保留原始前缀；穷举搜索保留其后续选择空间。

仅在最终输出或缓存完整映射时规范化：若尾元素p_k在P[:-1]下本来就映射到k，则删除这个无作用尾项，重复至不能删。不可随意删除内部元素。候选在当前邻域上的成本相同，不等于全域映射等价。

## 5. 首目标与搜索规则：完整冻结

### 5.1 静态首选

在π顺序评价所有单值 `[p]`，只在严格更小分数时替换当前best。结果记为B。其K=1输出必须与旧STATIC_EQ／STATIC_SP逐位置映射一致。

若首选为恒等，**搜索内部将B表示为[1]**，并允许后续探索[1,q]；这不是把0映射为1。若n<3，则仍完全禁止扩展。

K定义为最多冻结／指定的目标等级数，包括显式的1和零收益占位，不是实际改动幅值数。有效深度为`min(K,|V|)`。

### 5.2 G：严格改善贪心

从B开始。在当前P下，对每个未选q计算`G(q)=S(P)−S(P+[q])`，选G最大的q；并列遵守π。

仅当最大G>0才追加q；否则立即停止。达到K或候选耗尽也停止。输出当前P。

G逐步保证所用静态分数严格下降，但不是深度K空间的全局最优，也不保证CABAC改善。

### 5.3 N：允许零收益过渡的单路径贪心

首选同G。每轮仍选同一个最佳q，但G=0也允许追加，继续下一等级；G<0才停止。

沿途只在S严格下降时更新`bestPrefix`，因此同分保留最早／最短前缀；输出bestPrefix而不是强制输出最后的长列表。

保留零收益步是为了跨过码长平台，**不是允许付出暂时更差的静态分数**。只沿确定性的一条平局路径前进，不声称穷举所有平台分支。

### 5.4 P：保护幅值1的独立路线

将根固定为[1]，其后采用G。第一目标也占K中的一个名额，因此P2表示1保持、另选一个值映射到2。

此路线只保证不劣于自己的恒等根，不保证不劣于STATIC_EQ；不能事后偷偷回退STATIC_EQ，否则它不再是纯保护1对照。

### 5.5 D：两根搜索

分别从B和[1]运行G到同一最大K，比较完整静态分数，取更小者；并列保留B路线。根已相同则只计算一次。

该组用于检验固定首选的损失，不增加第三条起始路线，不用真实当前幅值或CABAC结果选路线。

### 5.6 X：小深度完整组合对照

穷举V上长度0..K的全部不同正值有序前缀，K只取2／3；允许跨过零或负的中间增量，但最终按静态S选择。

最终比较键：先S；并列优先选择与静态根B相同的映射；然后规范化后的短动作；最后按π索引序列的字典序。相同最终映射可去重，其不同未完成搜索状态不得提前合并。

M=6时，K=2／3最多分别37／157个前缀（含空），可作为离线静态搜索质量对照。**X是代理分数的最优，不是实际CABAC最优oracle。**

## 7. 精确快算法合同

### 7.1 增量公式

当前前缀P长度k，下一目标等级t=k+1，未选候选q的当前等级r_q=f_P(q)。定义：

`G(q)=W(q)*(C(r_q)−C(t)) − sum_{v未选,v<q} W(v)*(C(r_v+1)−C(r_v))`。

这是完整重评分的恒等式，不是近似。所有未选幅值在当前映射中仍按原数值顺序排列。

一次升序扫描维护累计挤占损失A：

```
A = 0
for v in sorted(unselected observations UNION unselected candidates):
    if v is a candidate:
        G[v] = W[v] * (C(rank[v]) - C(t)) - A
        compare G[v] with best, using original priority pi on ties
    if any candidate remains strictly above v:
        A += W[v] * (C(rank[v]+1) - C(rank[v]))
```

在最大候选之后不再需要累计，也不要查询C(Amax+1)。选中q后，只有原来满足`t<=rank[v]<r_q`的未选项等级加1；q从未选表移除；固定前缀样本不变。

### 7.2 三个实现引擎

- `NAIVE`：独立构造完整试探映射，对全部观测重评分；作为清楚的参考。
- `PREFIX`：使用上述共享前缀增量、缓存等级与成本；不做候选支配剪枝。
- `FAST`：PREFIX加当前轮次的码长平台代表与安全短路。

每个引擎必须产生相同S、tie赢家、搜索轨迹、返回前缀及全域映射。只在当前q上的映射相同不够。X的FAST仅复用可证等价的评分缓存，不用贪心支配删除整个组合分支。

### 7.3 允许的剪枝及适用范围

当前C为公共、非递减、固定的加性成本，才能使用：

1. 合并重复幅值的计算，保留其全部W。
2. 同一成本平台C(r)=c中，若c>C(t)，仅最大W候选能够赢本轮；W相同按π。若c=C(t)，支持数不区分候选，只保留π最优者。
3. G模式中，W(q)=0或C(r_q)=C(t)不能产生严格正增量，可跳过其胜出比较。**N模式可能需要这些零增量占位，不能直接删除。**
4. 若所有剩余有支持样本都已处于C(t)平台，后续非递减目标成本不能再严格改善；对本规范“同分保留最短前缀”的输出可安全终止。

平台淘汰只针对当前轮次，观察样本仍参与A；下一轮必须重新考虑。平台同分只保证代理选择等价，不保证真实CABAC码长等价；不能任意更换原tie代表。

不将“一轮没有正收益”当成所有更深映射无收益的证明。复杂乐观下界、排序概率堆、经验margin门槛首版默认不启用。

### 7.4 复杂度要求

设U为不同观测数≤5，M为候选数≤6。朴素逐候选重扫是O(nMK)评分项，额外的映射构造成本还需计入。排序／合并之后，增量快版目标为O(K(U+M))，小数组O(U+M+K)空间。

M=6时K=2/3/4/6的候选扩展项最多为11/15/18/21；这些不是CPU时间比例，也不包括所有码长查询、去重、逆映射及真实解码。

同一条贪心轨迹可以保存多个K的结果，但仍分别执行完整TU费用回放。N的bestPrefix不能被更深的零收益尾项覆盖。

## 8. 必须保留的精确反例与验收输入

- H=(1,2,2,6,8)：π为2,1,6,8；静态首选[8]得15。第二轮1/2/6的G均0，π选2；[8,2]仍15，[8,2,6]为14。G停止而N可通过该平台，不能用“零增量无用”剪掉2。

- P=(p,1)与[p]输出等价，但搜索前缀不同；P=(1,2)与空映射等价；前缀中的0或重复幅值必须拒绝。

## 9. 回放与编码接口：必须传完整动作

旧 `replayRateCG` 的 `predict(s)` 返回一个整数，再调用旧remap；现有61列整数pred schedule不能表达本设计。

新增动作建议为：

```
MappingAction { uint8_t count; Magnitude targets[6]; }
mapMagnitude(a, action)
unmapMagnitude(y, action)
```

动作描述必须在看到当前真实a之前，由同一因果H生成。禁止看到a后选一个虚拟单pred使单个等级碰巧相同。

新schedule应版本化（建议协议名`TS-MG-ACTION-v1`），记录有序列表／字典id，而不是仅输出映射后的当前等级。绑定流、来源、TU几何、完整q摘要、入口context摘要、扫描摘要、评分／候选／tie版本和21组目录SHA。

完整动作可在同TU内去重。搜索状态不因动作当前等价而合并。回放缓存只有在固定q、固定入口及全部语法条件相同时，才可按完整映射行为复用。

### 9.1 真实码流仍按原模式解码

R13-1来源按R13-1原生规则解码，R13-2来源按R13-2原生规则解码。新增多目标只在副本中回放，不用新逆映射直接解释旧.bin。

每个目标TU记录TSRC开始前的完整Ctx，恢复最终q后再评价。不同CG连续更新概率和regular-bin预算，不能每CG重置。

### 9.2 映射应用范围不扩大

沿用原TSRC对regular映射和cutoff的时序：原来映射的语法路径改用新完整映射；纯bypass/cutoff=0路径继续使用真实幅值，不因多目标而扩大适用范围。sign、sig、CG flag和BDPCM处理保持原逻辑。

每条私有分支独立推进预算和三遍边界。不能冻结原生pass边界后只改幅值；新增映射可能消耗更多regular bin，从而影响后续位置。

针对任意合法MappingAction补充局部Writer→Reader语法fixture；旧单值／空映射必须与旧实现完全一致。测试用局部语法编解码不是视频EncoderApp运行。

## 10. 运行阶段与资源合同

## 11. 三类结果：静态分数、真实费用、复杂度

### 11.1 主要费用比较

主指标沿用已冻结口径：每来源的`R_ref−R_method`除以自身非零数，两个来源各1/2，再内容内四QP等权，最后12内容等权。正数表示节省。

参考至少为Current和STATIC_EQ；SP组另外对STATIC_SP。原R13_EQ/SP的条件费用只作历史辅助列。YUV费用直接相加，不用BD-rate的6:1:1权重。

同时报告：原始bit总量、原始合计节省、逐来源方向、各序列／QP／分量、有支持单元数、改善／持平／增码TU数、累计正损失、最坏TU、正损失分位。空人口不填0。

有754151个块不等于有754151个独立内容；不以此制造过窄置信区间。主指标、原始合计和尾部同时保留，不根据哪个更好临时换冠军。

### 11.2 “新增目标”究竟有没有实际作用

全量廉价统计：n、不同幅值数、候选数、搜索原始深度、规范化有效深度、各层正/零/负增量次数、neutral占位次数、最终返回哪个前缀、首选被保护1/两根/穷举改变次数。

必须区分：候选目标新增 → 最终动作改变 → 当前幅值映射改变 → 真实regular路径生效 → 完整TU费用改变。

幅值0/1/2/3–4/5–8/≥9按事后观察分层，标注只用于诊断。真实a不得参与选择或门槛。

### 11.3 区分搜索不足与评分不足

- 同动作池内，`S(G_K)−S(X_K)`衡量静态搜索损失；不能称CABAC损失。
- 代理分数更低但整TUrate更高，说明静态目标不足以解释实际费用；若仍只看总分会误判成功。
- 局部真实最优标签需要对动作做同q同入口单位置干预，不能由整TU策略rate反推出逐系数oracle。

首轮不强制生成全量高代价单点标签。预注册可选诊断：每条正式流用稳定哈希均匀保留最多64个`a>0,n>=3`位置，另保留最多32个方法分歧位置；来源／序列／QP一致规则，二者分开统计并记录包含概率。每位置比较MG00/01/02和21组实际提出的不同完整动作，其余位置保持来源原生映射；这只是“已提出动作集合”的局部最优，不是全部深度6映射的全局oracle。CE01指定回归单独人口。

这些标签可定位具体误判，但不能与全量结果混成全量准确率。既有数据被反复用于开发，留一内容选组也不能宣称全新盲测。

### 11.4 两种独立复杂度测量

算法级：同一H、Rice、动态范围和固定组号，在NAIVE/PREFIX/FAST上测相同的动作输出；报告候选评测项、码长查询、查表命中、整数加法/乘法/比较、等级更新、平台淘汰、循环次数。

运行级：同一机器、编译器、线程、CPU设置，对预提取的H trace做selector基准，预热后至少5次、轮换运行顺序、输出校验防止被优化掉；另测完整审计流程，但不得将昂贵CABAC回放耗时称为实际编解码复杂度。

选择器开销、map/unmap开销、整个解码开销分别报告。生产编码器复杂度在未运行EncoderApp前保持“未测”。不从O(MK)推出固定速度倍数。

## 13. 放行标准与后续闭环边界

### 必须通过的硬验收

1. 全合法幅值上的正反映射／边界与旧单值一致性；C++、Python得到相同动作。
2. 三引擎同组逐位置score、tie赢家、完整前缀/最终全域映射一致；尤其零收益平台、候选1和无作用尾项。
3. MG02/03与旧STATIC_EQ/SP逐位置/逐TU等价；MG04与MG08最终动作等价。
4. 更新当前a、未来q或来源标签不会改变当前动作；前缀搜索不产生跨系数可变历史。
5. 主解码原生bins/context/budget/pass与重建不变；旧模式回归不变；全部21列对每个有效TU完整存在。
6. 全96任务EOF、四QP两来源齐全；预算、LFS指针、错误身份、损坏动作、缺列均明确拒绝。

### 性能判断不预设成功

在正确性通过后，保留平均与尾部的Pareto候选，最多选择2～3个方案继续。不能仅因相对Current为正就说多目标有效，应重点对STATIC_EQ的新增收益及复杂度。

若增加K只改善score却恶化真实rate，优先研究代价指标，不继续增加目标。若X显著降低score而G达不到，才考虑两根或小宽度搜索；若X真实rate也不佳，不能归罪于快算法。若FAST没有实测速优势，可以保留PREFIX小数组版本。

### 将来获准进入编码器时

当前映射必须在RDOQ前固定，不在每个量化候选中重新选P。原零候选、CG清零及RD竞争不变；对每个合法level用完整map计算非零语法成本。

新增目标映射到2..K不自动获得额外+1试探。将原普通路径“上取整命中等级1”的门槛按完整映射一致迁移，保留原epsilon与其它限制；这个谓词的结果可能因映射而变，须记录，不能声称量化候选数必然恒定。为目标2..K开放上取整属于后续独立实验。

Writer/Reader共享同一动作选择、候选和tie；各自只能使用已恢复因果幅值，三遍语法不重复改变选择。新映射要求匹配的新编码器／解码器，不兼容旧的隐式映射假设。

闭环需另外报告真实bit/PSNR、解码hash、CTC/BD-rate、编码/解码时间以及搜索差点；本轮不提前登记这些结果。
