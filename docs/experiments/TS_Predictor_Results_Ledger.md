## 记录口径

- 唯一基线为 **Current**。除单独标明的历史诊断外，下表均为闭环编码对 Current 的 BD-rate，单位 **%**，负数表示码率节省。
- 每序列先分别计算 Y/U/V 的四点 PCHIP BD-rate，再计算 `BD611=(6*BD_Y+BD_U+BD_V)/8`；不先加权 PSNR。
- 类别和类别组合均按序列等权。完整 CE 为 `(4*C+3*E)/7`，BCE 为 `(5*B+4*C+3*E)/12`，CD 为 `(4*C+4*D)/8`。
- QP 为 22/27/32/37；LB 沿用半帧实验口径。CE、B、BCE、CD 的完整点数分别为 28、20、48、32。
- 下列 LB CE 表中，Y/U/V 是该行所列 CE 集合的分量均值；C、E、CE 列均为 BD611。A3 的六序列子集单独标明。
- `实测`表示源结果中有该点数值；不等于本轮重新编码或完成服务器程序身份、帧范围、解码 hash 核验。具体核验范围见来源报告。
- `*`表示对应统计范围内含 Current anchor 补点；不算实测。`—`表示尚无已记录数值，不是 0%。
- 汇总 BD-rate 显示六位小数；逐 QP Markdown 显示四位，CSV 保留源表数值。R8 原先仅外部转录的部分已由本地源表复算。
