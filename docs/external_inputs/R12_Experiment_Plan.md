## 2. 共同定义与R3语义

### 2.1 原R3-1不是“删一个样本后仍对全部候选最优”

当前位置的五个因果幅值按固定槽位排列：

```math
h=(L,U,D,LL,UU),\qquad p_{\mathrm{cur}}=\max(L,U).
```

D为左上，LL/UU为左二/上二。零幅值不进入非零评分样本；真实不存在与已知零必须在可得性逻辑中区分。p=0/1规范化为同一个identity动作。

原幅值映射：

```math
M(a,p)=\begin{cases}
0,&a=0,\\
1,&a=p>0,\\
a+1,&0<a<p,\\
a,&a>p.
\end{cases}
```

对p=0/1实现统一identity。原R3先在P0中找整数总cost最小候选p*，再定义相对Current的逐样本节省：

```math
d_j(p^*)=c_I(M(a_j,p_{\mathrm{cur}}))-c_I(M(a_j,p^*)),\quad
G=\sum_jd_j,\quad H=G-\max(0,\max_jd_j).
```

只有H>0才接受p*，否则Current。删除的是**最大正节省贡献**，不是最小绝对cost；检查的是是否仍优于Current，不是删除后重新对全部候选求最优。n<3仍Current。P0={0,p_cur,非零邻居幅值}，Current优先平局，其后identity、较小幅值。

### 2.2 R10-3的两层不同位置

专家A=R8-12，B=整数Raw R2-2，C=整数Current-guard R3-1，均为不递归的纯函数。A仍依赖CG入口冻结fractional表。

外层验证集V0(i)：当前位置L/U/D/LL/UU中，同CG、真实存在、非零、原生scan更早的位置j，最多5个。每个j先用它自己的更早邻域h_j产生专家动作，再评价已知目标a_j：

```math
\ell^I_{ej}=c_I(M(a_j,p_e(h_j))),\quad
\ell^F_{ej}=c_F(M(a_j,p_e(h_j));s_i,d(h_j)),\\
L_I(e)=\sum_{j\in V_0(i)}\ell^I_{ej},\quad
L_F(e)=\sum_{j\in V_0(i)}\ell^F_{ej}.
```

s_i为当前CG入口冻结快照；d(h_j)为历史目标自己的L/U非零分类；CF使用cutoff=10。当前事后实际cutoff不能进入公共选择。

R10-3先最小化L_I，仅在其最小集合T0中最小化L_F，最终按A→B→C平局；空集A。

**内层加权**作用于h_j里相对j的位置，改变专家怎样生成p；**外层加权**作用于验证目标j相对当前i的位置，改变相信哪个专家。两者不能混写。

### 2.3 数值与比较

整数cost移到相同定点尺度后，一单位为 `Q = int64_t(1) << SCALE_BITS`。Q不是QP、阈值概率或真实CABAC一比特保证。差Q只是最小正代理差距，不代表统计意义上的低置信度。

定义T0=argmin L_I，e0为完整R10-3选择。新增候选的CF比较只在**严格低于e0的CF损失**时切换；CF相同保留e0，多个严格改善者再按固定专家顺序打平。原精确CI平局仍保留原A→B→C规则。

n_eff统计V0中至少两个专家对历史目标产生不同映射幅值的位置数，不是CI数值是否不同。不得因当前动作相同就合并历史行为不同的专家身份。

## 4. 完善原R12-1～6

### R12-1：先保护原精确平局，再开放差Q候选

若|T0|>1，直接返回e0；原来的T1={e:L_I(e)-min≤Q}会把差Q的第三专家加入原精确平局，不能声称行为不变。

仅|T0|=1、赢家w时构造：

```math
T_1=\{w\}\cup\{e:0<L_I(e)-L_I(w)\le Q\}.
```

在完整V0上按2.3的严格CF改善规则比较T1。差距超过Q不开放，不用样本数归一化后再比较Q。

### R12-2：同样只处理原唯一CI赢家

原精确平局保持e0。唯一赢家w时，仅当C不等于w且0<L_I(C)-L_I(w)≤Q，比较{w,C}；否则e0。不是强制回R3。R3已有平均结果不是局部安全保证。

### R12-3：修正遗漏下界和候选集合

D(h)=canonical(max(L,U))。先计算原ABC与T0，原精确平局或空V0保持e0。仅唯一赢家w且

```math
0\le L_I(D)-L_I(w)\le Q
```

时比较{w,D}；不把其余旧near候选一起加入。旧条件仅“≤Q”会错误包含D领先很多的状态，与只研究近似平局矛盾。本版有意不开放D远优或远差情形，这是实验作用范围，不是声称它们不值得研究。

计算D时历史目标也用自己的h_j；若D可能参与，快捷返回必须检查D，不能只看ABC当前动作相同。最终CF相同仍保持w。

### R12-4：删除后必须仍有有效证据

只处理原唯一CI赢家w。若n_eff<2，保持e0。对每个有效位置r，计算L_I^(-r)(e)=L_I(e)-ellI(e,r)。删除后仍须至少一个有效位置；不把“删光唯一证据后所有专家平局”作为不稳定性证据。

U_LOO为{w}与所有合法删一情景的CI最小专家集合之并。若U_LOO只有w，保持e0；否则在**完整原V0**上用严格CF改善规则比较U_LOO。不是删掉样本后编码，也不强制回A。

n_eff≥2只是启动这项敏感性检验的条件，不是给R10-3的一般选择加门槛；一个有效样本仍能正常驱动原选择。

### R12-5：保留为独立的硬空间优先对照

只用V0中L/U位置形成V_D。V_D非空且CI有唯一赢家时采用它；否则完整e0。这里可能改变原全V0的精确平局甚至强赢家，不能沿用1～4的“仅弱唯一赢家改变”保证。本组与9的软空间权重配对，而不是据旧扩邻域失败就推定L/U一定更好。

### R12-6：改成真正的并集组合

原精确平局保持e0。唯一赢家w时，U_C={C}仅在C满足2的near条件时存在；U_LOO按4计算，无合法删一情景时为{w}。

```math
T_6=U_{\mathrm{LOO}}\cup U_C.
```

在完整V0上严格CF改善才切换。即便LOO没有触发，C满足near条件也能参加；即便C不near，LOO找到的其他挑战者也能参加。这样才与基线/2/4/6构成明确四角。旧稿先要求unstable，再加C，实际上关闭了2的一部分作用范围。

## 5. 新思路：位置权重不是“加严或放松一个统一阈值”

首轮固定：

```math
(w_L,w_U,w_D,w_{LL},w_{UU})=(2,2,1,1,1).
```

直接相邻L/U与其它三个位置区分；横纵对称，不根据幅值大小、正负收益或预测方向动态调权。2:1是待检验的空间相关性假设，不是已测出的最优值。D虽然欧氏距离更近，本轮按曼哈顿层级与LL/UU同权；先不展开权重扫描。

对任意候选p：

```math
S_w(p)=\sum_jw_jc_I(M(a_j,p)),\qquad
G_w(p)=\sum_jw_jd_j(p).
```

加权同时强调近邻的收益与损失，不是只放大有利证据。权重2不是两个独立样本；不改变n<3，不以权重和代替样本数，不填充缺失邻居。零值仍按原规则跳过。必须保留L/U/D/LL/UU槽位，不能先压成无位置的nz数组再把前两项乘2。

实例（原整数cost的幅值1/2/3代价为1/3/3）：

| h=(L,U,D,LL,UU) | Current等价动作 | p=2未加权节省G | 原guard H | 加权节省G_w(p=2) |
|---|---:|---:|---:|---:|
| (0,0,1,2,2) | identity | 2 | 0 | 2 |
| (0,1,0,2,2) | identity | 2 | 0 | 0 |

两组非零幅值都是{1,2,2}。旧guard都拒绝；新加权raw接受第一组的p=2，第二组因直接邻居U=1提供更强反证，维持Current平局。这是代数例子，不是视频收益统计。

加权估计的是证据相关性；删最大项控制的是单样本支配。前者不会自动消除同样本选候选再评分的偏差，后者也没有证明所有位置应被同样怀疑。因此分开测试两者。

## 6. R12-7/8/11：改进R3式C专家，外层先保持不变

三组都仅替换C。A、B、V0、外层CI→CF与空集A均保持R10-3；C必须同时用于当前位置h_i和历史目标自己的h_j，不能当前换新C却用旧C的历史表现评它。C内部使用CI，不同时改成fractional。

C的n<3、P0、identity、Current-first平局全部不变。n≥3时先最小化S_w，得到同一个p_w。对于p_w计算G_w。

### R12-7：用位置加权替代硬删除

G_w>0则采用p_w，否则Current；不再减最大贡献。让有价值的近邻证据保留下来，也保留近邻反证。这不是无条件相信最大幅值或全局回Raw：C仍按位置加权搜索，外层再因果选择ABC。

### R12-8：同样加权，但保留原式稳健删除

```math
H_{\mathrm{full}}=G_w-\max(0,\max_jw_jd_j).
```

仅H_full>0接受p_w，否则Current。删除的是一个位置的整个加权贡献，不能把w=2当作两个独立观测而只删除其中一个。

7与8的候选集、权重、cost和p_w一致，只差删除规则。8检验“只改变位置相关性是否有效”，7进一步检验“是否必须取消硬删除”。

### R12-11：位置相关的部分删除

预设直接邻居删去其正贡献的1/2，其余位置删去全部：rho=(1/2,1/2,1,1,1)。

```math
H_{\mathrm{soft}}=G_w-\max(0,\max_j\rho_jw_jd_j)
                =G_w-\max(0,\max_jd_j).
```

后一等式仅针对本轮W成立，使用整数实现即可。它有意允许靠一个直接邻居的部分证据通过，因此不声称保留了旧“删除一个位置后仍获益”的保证。

同一个h、cost和p_w下：H_full≤H_soft≤G_w，所以接受集合满足完整删除⊆部分删除⊆不删除。这给出可验证的强度次序，但完整闭环收益没有此单调保证。

R12-7/8/11可以共享映射与cost矩阵，分别累计加权分数/贡献；不要重复读三遍同一邻域。替换C后，不可再假设B和C仍完全共享原rateDecision结果。

## 7. R12-9/10：只给外层验证目标加位置权重

这里A/B/C三个原专家都不变。对当前i，j若是L/U则w_ij=2，若为D/LL/UU则1；仍只取V0的合格位置，不增加更远样本，不跨CG。

### R12-9：CI和CF都使用空间权重

```math
L_I^w(e)=\sum_{j\in V_0}w_{ij}\ell^I_{ej},\qquad
L_F^w(e)=\sum_{j\in V_0}w_{ij}\ell^F_{ej}.
```

先最小化加权CI，在其最小集合内最小化加权CF，最终A→B→C。它可能改变原CI强赢家，是独立算法试验，不声称只改near1。所有专家使用同一组权重；不需要除以权重和，也不要给不同专家单独归一化。

这与R10-4的状态匹配权重不同：R10-4看z(h_j)是否等于z(h_i)，本组只看j相对i的几何距离。它也与R12-5不同：远邻证据始终保留，而不是L/U一有唯一赢家就完全覆盖远邻。

### R12-10：只在原精确CI平局内加权CF

原L_I和T0完全保持；T0只有一个专家则保持e0。否则在T0内最小化L_F^w，最终固定平局。与9相比，只改变CF阶段；与R10-3相比，不改整数唯一赢家。它不是R11-2的query分类重定位，CF分类仍是d(h_j)。

## 8. R12-12：内层和外层的预设组合

用7的加权raw C产生当前位置和所有历史目标的动作，同时用9的外层加权CI/CF选择ABC。不加入near1、LOO、保护1、新专家D或动态方向。

四角为R10-3、7、9、12。7/9/12不是将逐序列最佳结果拼接，不把两个BD-rate相加推算组合收益。交互定量分析须使用四条曲线共同质量区间。

## 9. 与历史位置加权的区别

旧R4-4使用e_h=|L-LL|+|U-D|、e_v=|U-UU|+|L-D|决定横轴或纵轴的1/2权重，方向推导要求完整模板；同时在加权排序后删除完整最大加权贡献。其CE约-0.025079%，直接对R3约+0.068162%，不应忽略这项负面结果。

但它同时绑定了方向推导、内层排序和完整删除，没有单独验证本轮固定距离raw、部分删除或外层历史目标加权。R4-4失败不等于所有位置权重无效，本轮也不是重跑同一个R4-4改名。

R10-4是特征状态匹配加权；R11-3/4是扩大验证集合；R12-5是直接邻居硬优先。本轮9/10的V0不变，7/8/11改的是C内部原五邻域。必须记录具体在哪一层加权，防止结果归因混乱。

## 10. 统计、正确性与复杂度

### 10.1 分组不变量

1/2/3/4/6：原精确CI平局状态保持完整R10-3；只在规定原唯一赢家状态开放。10：原CI唯一赢家保持；5/7/8/9/11/12无此保证。所有保证是同一输入状态的局部等价，不是整条闭环轨迹不变。

7/8/11：同输入raw p_w必须相同；接受集合嵌套。7在全部权重相同时等价整数Raw，不是R3；8在全部权重相同时等价原R3。固定W下L↔U、LL↔UU交换应对称。

所有组：先检查真实可得性和原生scan，再读幅值；当前/未来污染不能改变决策。Writer、Reader、RDOQ和replay同一规则；不读当前目标a_i、真实事后cutoff或未来参考。BDPCM/pure bypass沿用原路径。64位累计、CG清零、q编辑、分支复制/回滚及快照失效均需检查。

### 10.2 必备低开销观察

内层分开记录：w、p_cur、未加权/加权raw赢家、逐槽位d_j、最大贡献位置、G/G_w、full/soft guard、C新旧动作。外层记录V0槽位、n_eff、CI gap、exact tie、near challenger、LOO合法删除数、direct赢家、加权/未加权专家选择。

最终目标确定后再记录新旧动作的实际remap、各专家target loss/regret以及最终提交；这些事后量不能回流公共决策。相同q上的shadow改善不是完整编码收益，验证集上的最小regret也不是预测准确率。

每次只观察正在比较的少数模式，优先在CE既有基线轨迹上短测；B统计先复用已有日志，确需新增时只给通过资源门槛的少数候选或单独声明的基线诊断。不要默认给完整CTC开启全部模式高维shadow。

### 10.3 复杂度

固定V≤5和候选K≤6时整体仍O(N)，但主线原专家评估有非小常数。位置权重只用1/2，单次加权累计主要为整数加法/左移；7/8/11改变C计算，可复用B的映射/cost矩阵而非直接复用其最终决定。不得把w=2复制成两行，或把局部V变成全CG前缀以声称等价加速。

任何速度结论需关闭统计后同机配对计时，不能预报百分比。
