# R12实验设计：只修正R10-3的弱置信整数唯一赢家

## 1. 目标与共同基线

共同基线固定为 **R10-3**。本轮不是重新设计专家预测器，而是检验R10-3仍未处理的“整数唯一赢家是否过于粗糙”。

R10-3先计算A=R8-12、B=R2-2、C=R3三个专家在局部历史集合V0上的整数验证损失：

\`\`\`math
L_I(e)=\sum_{j\in V_0} C_I(M(a_j,p_e(h_j))).
\`\`\`

若存在多个CI最小专家，才用fractional损失：

\`\`\`math
L_F(e)=\sum_{j\in V_0} C_F(M(a_j,p_e(h_j));d(h_j)).
\`\`\`

打破平局。R12保留这一exact-tie规则。

整数 `syntaxCost` 的非零幅值成本是离散阶梯：
- level 1：1
- level 2/3：3
- level 4/5：4
- level 6/7：5
- level 8/9：6
- 更大幅值再加Rice长度

因此最小正整数代价量子是1。R12把“比最佳CI只差1个整数代价单位”的专家视为**最弱的非平局不确定区**，而不是任意扫描连续阈值。

令：

\`\`\`math
Q=1\ll SCALE\_BITS,\qquad
\Delta_e=L_I(e)-L_I^{\min}.
\`\`\`

除明示项外，V0、A/B/C、映射、RDOQ、YUV范围、BDPCM/bypass、概率冻结和tie顺序全部保持R10-3。

## 2. 配置总表

| 编号 | 工程标识 | 唯一主要改动 | 直接对照 |
|---|---|---|---|
| R12-1 | ci_near1 | CI≤min+1量子的专家进入CF竞争 | R10-3 |
| R12-2 | r3_near1 | 只允许R3专家C在差1量子时挑战CI赢家 | R10-3 / R12-1 |
| R12-3 | current_near1 | 只在差1量子时临时加入native Current challenger | R10-3 |
| R12-4 | loo_unstable_cf | 唯一CI赢家对单样本删除不稳定时改用CF重决策 | R10-3 |
| R12-5 | direct_first | L/U有效直接证据能唯一决定时优先；否则回完整V0 | R10-3 |
| R12-6 | r3_near1_loo | 预设组合：R12-2 + R12-4 | R10-3 / 2 / 4 |

第一批优先R12-1～5；R12-6在同轮实现但可等1/2/4短测活动确认后再完整跑CE。不要因为首批结果临时增加Q=2/3等参数扫描。

## 3. R12-1：一个CI量子的near-tie

先按R10-3得到 `L_I^{min}`。构造：

\`\`\`math
T_1=\{e: L_I(e)-L_I^{\min}\le Q\}.
\`\`\`

- 若 `|T_1|=1`：完全保持原唯一CI赢家；
- 若 `|T_1|>1`：在T1内使用原R10-3的CF_j损失选最小者；
- exact CI tie自然包含在T1中，并与R10-3行为一致；
- 最终平局A→B→C。

这不是CI/CF加权，也不是让fractional全面替代CI。它只把整数粗量化下最小的非零差距视作不确定。

必须记录：
- exact-tie数量；
- near1新增触发数量；
- near1后动作/实际remap变化；
- 当前目标事后target regret。

## 4. R12-2：只给R3一个near-tie安全挑战机会

保留R10-3的CI最小集合T0。若专家C=R3不在T0，但：

\`\`\`math
L_I(C)-L_I^{\min}\le Q,
\`\`\`

则只把C加入fractional竞争：

\`\`\`math
T=T_0\cup\{C\}.
\`\`\`

其它CI近一量子的A/B不因本组规则额外进入。

动机：R3完整LB B历史平均约−0.0506%，而R10-3仍在MarketPlace等内容存在退化；但R11-1已经证明“无证据统一回R3”会严重损失CE。因此这里只允许R3在**局部CI几乎无法区分**时挑战，而不是作为默认回退。

如果C已是CI最小或平局，本组严格等价R10-3。

## 5. R12-3：native Current只作为near-tie challenger

定义第四个纯动作专家D：

\`\`\`math
p_D(h)=\max(L,U).
\`\`\`

并用每个历史目标自己的h_j生成D动作及验证损失。

D不全局参加专家池。只有：

\`\`\`math
L_I(D)-\min_{e\in\{A,B,C\}}L_I(e)\le Q.
\`\`\`

时，才把D加入CF竞争；否则完全运行R10-3。

这与失败的R11-5不同：R11-5让Current在所有位置竞争，R12-3只在整数模型认为它与最佳专家几乎等价时开放。空集、强CI赢家等区域绝不改变。

最终tie仍A→B→C→D，避免新增专家因平局抢占旧行为。

## 6. R12-4：leave-one不稳定时才用CF重新决策

只处理R10-3中**唯一CI赢家**的状态。设赢家为e*。

对每个有效历史目标r，计算删除该目标后的：

\`\`\`math
L_I^{(-r)}(e)=L_I(e)-\ell^I_{e,r}.
\`\`\`

如果所有leave-one集合中e*都仍是唯一最小，则保持R10-3。

若存在任意r使：
- 另一个专家成为最小，或
- e*与其它专家产生CI并列，

则标记 `unstable=true`。

构造挑战集合U：包含完整集合的赢家以及所有leave-one情况下达到CI最小的专家。最终在**完整原V0**上比较这些U专家的CF损失，选最小者。

注意：
- 不删除样本后直接编码；
- 不回退A；
- 不扩大V0；
- 不使用未来目标；
- 与R10-5“删最大优势后回A”是不同算法。

本组检验的是：B薄弱是否来自一个历史样本恰好把粗整数损失推成唯一赢家。

## 7. R12-5：最直接的L/U证据优先，但只在能够明确决策时使用

从原V0中取L、U对应的有效历史目标集合V_D。

先在V_D上计算A/B/C的CI：
- 若V_D非空，且存在**唯一CI最小专家**，直接采用该专家；
- 若V_D为空或CI不能唯一决定，则完全回退到完整R10-3（V0 + exact-tie CF）。

第一版不在V_D唯一赢家上再用CF，不使用2:1方向权重。

该设计依据不是“方向预测一定更好”，而是R11-3/4已经表明增加更远历史会显著伤害闭环；本组反向检验更近证据在能够明确区分时是否更可靠。

风险：直接邻居也可能是偶然样本，因此必须记录direct-only赢家与完整V0赢家的分歧率和事后target regret。

## 8. R12-6：R3 near-tie + leave-one稳定性

预设组合，不根据结果重新定义：
1. 先按R12-4判断唯一CI赢家是否不稳定；
2. 若稳定，保持R10-3；
3. 若不稳定，则构造R12-4挑战集合U；
4. 若R3专家C距完整CI最小值≤Q，也加入U；
5. 在完整V0上用CF选择。

该组与R10-3 / R12-2 / R12-4形成固定四角。不要相加两组BD-rate预测组合收益。

## 9. 必备shadow诊断（R12-0，不是BD模式）

在真实R10-3最终Writer轨迹上，短测记录：
- `validation`、`n_eff`；
- A/B/C完整CI损失；
- 第一/第二CI差值 `ci_gap`（换算回整数单位）；
- exact tie / near1；
- leave-one winner集合及unstable；
- direct L/U有效样本数、direct赢家；
- R10-3赢家、R12-1～5 shadow赢家；
- 当前目标最终可得后的各专家CI/CF10/actual-cutoff CF target loss和regret。

优先短测内容：
- CE：BQMall、PartyScene、Johnny；
- B：MarketPlace、BasketballDrive、Cactus；
- QP27/32，固定少量帧。

目的不是从这些序列拟合新阈值，而是确认新规则确实有活动，并检查B薄弱内容是否比Cactus/CE拥有更多near1或unstable状态。

## 11. 不再重复的方向

本轮冻结不再测试：
- R11-1/7式无证据回R3；
- local8、跨CG、全CG历史；
- Current/NoPred全局第四专家；
- query-context CF替代；
- 任意CI/CF固定权重扫描；
- 按Class、序列、QP、分辨率或分量BD门控。

## 12. 正确性

所有新模式必须：
- Writer/Reader/RDOQ使用同一公共规则；
- 只读当前可因果取得的历史量化幅值；
- 不使用当前目标a_i、未来系数或事后cutoff选公共动作；
- 64位累计CI/CF；
- exact-tie区域验证与R10-3 bit-exact；
- 非near1/非unstable区域按模式要求与R10-3一致；
- 测试矩形TU、CG边界、n=0..5、全零/全1、动态范围、Rice、BDPCM/bypass、CG清零、q编辑和分支回滚；
- 统计关闭后做同机复杂度对比。

R12-0 shadow只用于事后诊断，不能进入当前决策。
