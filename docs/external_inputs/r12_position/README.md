# R12 修订与位置加权：参考实现及验证边界

本次按用户要求完善R12并加入按位置加权的测试；公开编号1～6保留，新增7～12。规格身份为 `R12-POS-01`。原稿保留在Git父提交 `cfa76d42f17ac96506dfdea4c7021f521d6603a7` 中。本目录不是codec实现目录，不改动生产脚本或旧模式。

## 修订内容

1. 原“min+Q”会把新专家加入旧的精确CI平局，不能同时声称平局bit-exact。现1/2/3/4/6首先保护旧精确平局，再处理唯一赢家。
2. 3的Current近似平局条件补齐下界 `0<=L_D-L_w<=Q`；负的大差距不再被误称为near。
3. 新CF比较相等时保留已有赢家，仅严格改善才切换，避免因编号制造无收益切换。
4. 4删除样本后须仍有区分证据；不把删除唯一有效样本后全体平局当稳定性证据。
5. 5是几何硬优先对照，可能改变旧精确平局，不再套用其它组的保留保证。
6. 6改为2与4的挑战集合并集，修正旧稿先要求LOO触发的AND语义。
7. 区分R3最大正节省删除与“删去最小cost”，也区分相对Current仍获益与删除后全候选最优。
8. R10-3的整体B匹配改善不能定位所有剩余误差；原稿中“exact-tie不是损失来源”等表述不能当作已证明事实。

## 新测试设计

- 7/8/11改C专家内部：固定W=(2,2,1,1,1)，分别不删除、完整加权删除、直接位置部分删除。
- 9/10只改外层验证：CI/CF同时加权，或只在原CI平局中给CF加权。
- 12是7+9的固定组合。
- 内层位置是样本相对其预测目标的位置；外层位置是历史目标相对当前目标的位置。保留槽位，不能先压缩nz后再加权。
- 旧R4-4采用动态方向权重且仍完整删除，不能据其均值未胜出排除本轮新机制；也不能忽略其失败经验。

## 运行

```bash
python docs/external_inputs/r12_position/r12_rule_reference.py /tmp/r12_validation.json
```

参考脚本仅使用Python标准库；已有 `validation.json` 来自本次实际执行。

检查包括：50,010个选择器/随机代数案例，7,776个小整数幅值邻域；原精确平局保护、Q缩放、Current双边门限、无有效剩余证据的LOO、并集组合、位置权重对称性、固定权重缩放、三种删除策略的接受集合包含性。

`small_ci`故意只覆盖0～9的小幅值cost，穷举不超出此范围；随机非单调cost测试仅验证代数，不能当成真实CABAC概率分布。参考输入是抽象损失矩阵，当前动作快捷返回和原生可得性由codec后续负责。

未验证：完整12模式的原生专家集成、真实scan与跨调用可得性、Writer/Reader/RDOQ同步、原生CABAC状态、视频BD-rate、运行耗时。没有把合成案例数量当作真实内容统计或实验收益。

旧R12若已在运行，不能覆盖二进制或直接复用resume。先核对规格/源码/二进制SHA，再登记本版结果。
