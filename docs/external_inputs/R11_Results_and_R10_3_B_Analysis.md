# R11结果与R10-3 Class B阶段性分析

## 1. 数据快照与结论

分析基于实验分支提交 `e6ba16bce2d1c1a6eb45a8340b7f27a22ab4b53b`（Record R11 CE and partial R10-3 B results without new imputation）。

R11-1～8 的 LB CE 均为 28/28 实测点，无补点。R10-3 的 Class B 当前为18/20实测：MarketPlace、RitualDance、Cactus四点完整；BQTerrace、BasketballDrive缺QP22，不进行新补点。

核心结论：
1. **R11没有版本直接优于R10-3。** 直接重新积分后，R11-1～8 相对R10-3的CE增量分别为 +0.08535、+0.00217、+0.13707、+0.10202、+0.08353、+0.09992、+0.12164、+0.17251%。
2. **R11-2几乎等价于R10-3，但并未推进主线。** CE为−0.15410%，R10-3为−0.15605%；R11-2的12个Class E RD点与R10-3相同，变化只发生在Class C。
3. **扩大验证样本、跨CG历史、无证据回R3、全局加入Current/NoPred专家均被本轮闭环结果否定为默认方向。** 这些机制可保留为诊断证据，不继续作为主线叠加。
4. **R10-3的fractional平局处理不是B退化来源。** 在五条B序列现有共同实测区间上，R10-3相对R9-9全部改善：BQTerrace约−0.275%、BasketballDrive−0.004%、Cactus−0.149%、MarketPlace−0.032%、RitualDance−0.064%。
5. B的剩余问题主要集中在R10-3没有改变的/仍然错误的决策，而不是exact-tie分支。下一轮应研究**整数唯一赢家中的弱置信决策**，而不是再次改大验证范围或全面扩专家池。

只有KristenAndSara获得大改善，其余大多退化。R11-7叠加query-context也没有修复。说明R10-3在“无结构性证据”时默认A的先验价值不能简单替换为R3。

### 2.2 R11-2：query-context只产生小范围重排

R11-2相对R10-3：
- BQMall −0.02016
- BasketballDrill −0.00864
- PartyScene +0.08430
- RaceHorsesC −0.04030
- FourPeople / Johnny / KristenAndSara 0

总均值 +0.00217%。因此，把exact CI tie的CF分类从历史目标状态改成当前query状态，不是后续主方向。它同时证明R10-3的主要结构已经较稳定：小幅改变tie评价只在少量内容产生变化。

### 2.3 R11-3 / 4：更多历史不是更好

同CG补到8个历史目标，直接退化+0.13707%；允许跨CG后仍退化+0.10202%。跨CG对某些C内容有补偿，但E整体仍转正。当前五邻域验证的“局部性”应保留；不要继续扩大半径、增加历史长度或建立全CG前缀。

### 2.4 R11-5 / 6：简单动作不应全局加入专家池

native Current和NoPred作为第四专家都明显退化。问题不是编码器缺少这两个动作，而是如果让它们在所有验证状态参与竞争，会改变大量原本有效的CE决策。若下一轮再次使用简单动作，只能限制在非常弱置信的局部状态。

B并非统一失效：BQTerrace/Cactus有较强改善，RitualDance小幅改善；主要薄弱是MarketPlace和BasketballDrive。不能按Class B整体关闭该工具。

### 3.2 R10-3相对R9-9的B改进

共同实测区间：
- BQTerrace −0.27536
- BasketballDrive −0.00373
- Cactus −0.14895
- MarketPlace −0.03183
- RitualDance −0.06391

因此，**R10-3的exact CI tie→fractional tie-break在B中也是正面机制**。下一轮不应回退R9-9，也不应取消fractional平局处理。

### 3.3 最终目标需要的B改进很小

如果当前CE保持R10-3：

\`\`\`math
BD_{CE}=-0.156054\%.
\`\`\`

为使12序列BCE达到−0.10%，Class B只需要：

\`\`\`math
BD_B\le \frac{-1.20-7(-0.156054)}{5}\approx -0.0215\%.
\`\`\`

若按当前阶段性估算，最终BCE约−0.095%，则等价B平均大约−0.0095%，距离目标只差约**0.012个百分点**。因此下一轮优先目标应是：

> **CE基本不动，只从B薄弱位置追回约0.01～0.02%的平均收益。**

这不需要也不应采用大范围新规则。

## 4. 对下一轮的约束

保留R10-3：
- 专家A/B/C不变；
- 原五邻域V0不变；
- 整数CI仍为主排序；
- exact CI tie仍用原fractional CF_j；
- 空集仍A；
- 不按Class、序列、分辨率、QP或Y/UV BD结果切换策略。

下一轮只允许修改：
1. **整数唯一赢家但CI优势非常小**的状态；
2. **单个历史样本就能改变赢家**的状态；
3. 在上述弱状态中有限引入R3或native Current作为challenger。

不重新测试：
- 全局无证据回R3；
- local8 / 跨CG扩历史；
- Current/NoPred全局第四专家；
- query-context CF作为默认替代；
- 固定CI/CF混合权重扫描。

后续规格见 `R12_Experiment_Plan.md`。
