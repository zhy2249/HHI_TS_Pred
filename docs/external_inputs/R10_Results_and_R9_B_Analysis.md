# R10-1～6 与 R9-9 Class B：数据分析和 R11 依据

## 1. 快照与结论

分析固定于 `zhy2249/HHI_TS_Pred` 的 `experiment/ts-predictor-study` 分支提交 `e1413fd0bf361cdea7d06fbc1b3a78c7036de5de`。源提交登记 R10-1～6 的 CE 和 R9-9 的 B 数据；R10-7 尚无结果。本文件为外部分析，不修改正式台账、源工作簿或源码。

**两个结论必须同时保留：R10-3 的 CE 为 −0.15605%，直接优于 R9-9 −0.03132%；但 R9-9 的 B 类已有实测数据确实暴露退化，不能因缺 QP22 而忽略。R10-3 尚无 B 数据，CE 改善不能证明 B 已修复。**

本次未重新编解码，未取得这些正式任务一一对应的 target-regret、运行环境、二进制及解码 hash；代码具备统计能力不等于已经拿到统计结果。

## 2. 完整性和计算口径

- R10-1～5：每组 28 个实测点；R10-6：26 实测，PartyScene 与 RaceHorsesC QP22 是台账已有的 Current 暂代点。共 166 实测、2 暂代。
- R9-9 B：16 实测；MarketPlace、Cactus、BasketballDrive、BQTerrace 的 QP22 是已有 Current 暂代，RitualDance 四点完整。CE 原有 28 实测未改变。
- 本次沿用并标注台账已有暂代，不新增补点授权。`full` 在台账中表示可组成曲线，并不等于全实测。
- 逐分量在 PSNR–log(总码率) 上做 PCHIP，在两版本共同质量域积分，不外推；随后 `BD611=(6BDY+BDU+BDV)/8`。C/E/CE 分别按 4/3/7 序列等权。直接增量重新积分，不相减对 Current 百分比。
- 低/中/高质量段保留四点曲线，只在 Current 各分量 QP32/27 的 PSNR 处分段；不是“单 QP BD-rate”。
- B 的纯实测诊断对所有五序列统一仅用 QP27/32/37，参考与测试都重新拟合三点曲线，不带入任何 QP22 暂代。它是受限质量区间诊断，不是完整四点 CTC 结论；不能与四点 CE 直接拼接成 BCE。
- 新数值从固定提交的 connector CSV 按编号读取并转录，36 个 C/E 分量汇总与仓库核对最大差约 6.74e-14 个百分点；B 暂估均值也一致。历史 R3/Current B 和 R9 CE 来自本会话已有逐点文件。复算包保留输入及验证脚本；不是原 XLSM 或完整日志的重新审核。

分量均值 Y +0.04295%、U +0.47137%、V +0.24414%，因此不能把问题简化为“只是色度损失”。仍需区分分量指标和对应 predictor 的因果效果。

### 5.2 无需任何插值的反例

BasketballDrive QP27：码率由 4130.4240 增至 4134.7376 kbps（+0.10443%），Y/U/V PSNR 分别下降 0.0008/0.0003/0.0010 dB。在表中精度下，率更高且三个质量都更低。RitualDance 的完整四个实测点也给出 +0.02888% 的 BD611。

这两项与五序列三点结果共同支持用户指出的跨内容问题；不应等补完 QP22 才开始研究。与此同时，Cactus 的实测区间仍相对 Current 改善，不能把所有 B 块都视为失败状态。

### 5.3 暂估值只作为上下文

使用台账已有四个 Current QP22 暂代时，B 为 +0.05864%，BCE 为 −0.04831%；R3 已有完整实测 BCE 为 −0.07552%。两者完整性不同，不据此宣称最终 BCE 排序已锁定。也不能把这套 B 结果拼到未测 B 的 R10-3 上预测新 BCE。

**当前判断：R9-9 是 CE 中有收益、但在当前 B 实测质量域显露退化的方法；R10-3 是新的 CE 候选，而非已经验证的跨类别替代版本。**

## 6. 从 R10 和代码中识别的设计问题

源码 `TsR10Prediction.h` 与实施说明确认：A=R8-12，B=R2-2，C=R3；验证集为五邻域内同 CG、非零、已知位置；每个历史目标用自己的更早邻域生成专家动作；只在整数最小集合内进行 CF 平局处理。

1. **缺乏证据时仍固定回 A。** 空验证集或历史映射对所有专家完全相同，均不能证明 A 最适合当前目标。当前最终 tie 默认 A。这是可检验的盲区，不是已证明的 B 损失来源。
2. **同 CG 限制丢弃了一部分已经可得的近邻目标。** 当前五点模板可能没有能区分专家的历史结果；不应只提高惩罚而不检查证据覆盖。扩大模板会带来分布漂移，因此必须拆分同CG扩展与跨CG扩展。
3. **CF_j回答的是历史目标条件下的代价，不必等于当前目标条件。** R10-3 的成功提示可保留整数约束，再单独测试将平局损失投影到当前目标的冻结分类。它不是用当前目标幅值或实时上下文偷看未来。
4. **专家池不保证含有原生 Current 或 NoPred 动作。** R3会回Current，但不总回；A会选NoPred，但不总选。三种高级规则可能共同遗漏一个简单动作。加入简单专家与强行回退不是同一实验。
5. **R10-5的“保守”只保护A，不保护Current/R3。** 当前 CE 退化不能证明所有拒绝机制无效，但不宜继续统一删更多历史证据。
6. **R10-4的粗状态加权没有改善本批结果。** 不能据此否定所有状态特征，但也没有理由在同一粗标签上继续盲扫权重。

没有正式残差特征日志，不能认定 B 的 TS 块一定更稀疏、幅值更小或验证集更空。R11 明确测试这些假说，不用 Class/分辨率/QP 开关来绕过问题。

## 7. R11 的范围与必要对照

详见 `R11_Experiment_Plan.md`。新增八组：无证据回R3、当前分类平局代价、同CG局部8点、跨CG同TU局部8点、加入Current、加入NoPred，以及两组预设组合。R10-3保留为CE基线，R9-9/R3作为跨内容对照。

每个 R11 在首轮就同时覆盖 CE 和 B 的共同实测 QP27/32/37；不再只以 CE 总榜决定哪个算法才有资格见 B。R10-3 的 B 必须独立补测；未测不能先称安全。最终完整结论仍需各四点齐全。R10-7结果到来后仍按原计划分析，不因本次缺数据将其取消。
