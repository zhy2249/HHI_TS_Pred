# CE优先：Class B与完整BCE双目标及候选排序

## 1. 用户最新目标

先选CE收益较高的版本，再用Class B确认；不是只选择B表现较好的旧算法。最终同一个版本必须同时满足：

```math
BD_B\le -0.04\%,\qquad BD_{BCE}\le -0.10\%.
```

本说明补充[Class B序列选择分析](ClassB_Test_Selection_Analysis.md)的候选优先级，不改变历史实测值、算法编号或源码。之前的相关性只用于帮助选测试序列，不能让CE偏弱的版本因为推测B会较好而优先消耗资源。

## 2. 由双目标反推CE预筛

沿用B五序列、CE七序列、总共12条等权：

```math
BD_{BCE}=\frac{7BD_{CE}+5BD_B}{12}.
```

当B恰好为−0.04%时，要使BCE≤−0.10%，需要：

```math
BD_{CE}\le\frac{12(-0.10)-5(-0.04)}{7}
=-0.1428571429\%.
```

这是以B目标边界计算的确定性算术，不是对未来B收益或泛化的保证。如果真实B明显优于−0.04%，CE偏弱也可能使最终BCE达标，但本轮资源策略不依靠这个未经实测的期待。

实际主候选门槛继续使用 **CE≤−0.15%**，且CE越好越优先。CE在−0.15%到−0.142857%之间只作为边缘储备，不优先测B；CE高于−0.142857%的版本默认不进入本轮B确认。最终结果仍检查两个真实指标，不能仅凭过了CE门槛宣称达标。

## 4. 有限资源的实际顺序

先补R10-3的BQTerrace QP22，确认基线完整B与BCE。同时，新候选顺序为：**R12-11 → R12-3 → R12-6（或4）**；根据前两组真实结果和剩余预算再决定第三组，不自动全开。

每个获准候选先Cactus、BQTerrace、MarketPlace × QP27/32/37，共9点。这些序列用于检查主要收益来源和主要风险，不是挑选有利内容计算平均。只对仍值得确认的少数候选，再补这三条QP22及BasketballDrive/RitualDance四QP，共11点。

B三点诊断不能替代四点正式平均；子集均值不用于认证B≤−0.04%，也不能与完整CE混成正式BCE。不能从R10-3借B给R12，也不能把不同版本的Y/U/V或逐序列最佳值拼接。

最终接受条件为同模式、同配置、可比运行身份的完整20点B和28点CE：

```text
B_mean <= -0.04  AND  BCE_mean <= -0.10
```

即使某版本已满足B≤−0.04%，若BCE仍未达到−0.10%，也不作为最终达标方案。反过来，即使CE很强使BCE达标，B没有达到−0.04%仍不满足本轮双目标。
