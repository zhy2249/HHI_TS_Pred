# Class B测试序列选择与CE/B相关性分析

## 1. 结论和适用范围

当前目标是**完整Class B五序列的BD611平均≤−0.04%**，不是只测试容易获益的序列后计算部分平均。

建议通过CE资源门槛的少数候选，先测试：**Cactus、BQTerrace、MarketPlace**。这三条分别覆盖较稳定的收益来源、可能贡献较大但容易丢失的收益、主要风险项。BasketballDrive列第四，RitualDance列第五；最终达标仍须五条四QP完整。

若一次只能测两条，先Cactus＋MarketPlace，再补BQTerrace；这优先检查是否保住收益来源和是否继续遭遇显著退化。若只问哪条更可能出现负BD，Cactus证据最强；BQTerrace具有收益潜力但不能称为稳定获益序列。只测Cactus＋BQTerrace会遗漏MarketPlace风险。

R10-3的BQTerrace QP22仍应单独优先补齐：这是基线唯一缺点，不需要重跑其它点。该任务与新候选的三点初筛分开安排。

固定仓库快照：`a4a92cbaa4f1f35d20f9ef8661bbf6613d381e1f`；原始结果快照为`a0f21db22e0ef2ed778a9e1a17aa4daa966fed45`。没有新增R12 B结果。本次未修改codec、未运行新编码、未改写正式台账。

## 2. 数据与方法

选择8个同时有完整CE和B五序列QP27/32/37实测覆盖的版本：Fixed-NoPred、Fixed-Directional、R3-1、R3-2、R6-2、R9-9、R10-3、R11-2。B诊断共120个实测点，相关性中不使用任何anchor暂代或缺失QP22。

- CE特征：各序列QP22/27/32/37四点BD611；C/E/CE按相应序列等权。
- B响应：双方仅使用实测QP27/32/37，重新拟合PCHIP后在共同质量区间积分。这是统一质量覆盖的三点诊断，**不是完整四点CTC B**。
- 对每个分量分别计算BD，再按(6Y+U+V)/8加权；不先加权PSNR。三个分量共享整码流码率轴，不能把结果直接归因于对应分量predictor。
- 同时计算Pearson、Spearman、删一版本、排除固定预测器及删除R3-2的敏感性；另外检查按方法族删除后的变化。
- 8个版本不是8次独立随机实验。R3-1/2共享大量结果，R9/R10/R11也高度相关；多轮开发与选择偏差均存在。相关性不能变成可靠收益预测、置信概率或因果结论。
- 四套完整五序列B复算与台账均值对照的最大误差为4.95e−15个百分点以内。R11-2的四条C序列特征采用报告六位小数值，其舍入量远小于相关性分析的不确定性。

输入来源是已有会话复算包及本次读取的固定提交逐点台账/逐序列汇总。`audit.json`记录边界，脚本不会联网或运行编码器。

## 3. 哪些B序列更可能产生收益？

以下均相对Current，单位%。星号仅代表三点实测区间；不得把带星号项与四点值混算正式B。

| 序列 | R3-1四点 | R6-2四点 | R10-3最新结果 | 本轮测试角色 |
|---|---:|---:|---:|---|
| Cactus | −0.17449 | −0.19995 | −0.20651 | 优先检查主要收益能否保持 |
| BQTerrace | −0.10985 | +0.04132 | −0.09369* | 可能贡献较大，也容易翻转，应恢复首轮优先级 |
| MarketPlace | +0.01361 | −0.07290 | +0.13044 | 主要风险项，同时存在可改善的历史证据 |
| BasketballDrive | +0.06136 | −0.03114 | +0.04194 | 次级风险；本轮第四优先，不是永久跳过 |
| RitualDance | −0.04387 | −0.00487 | −0.03542 | 最终确认项；不能假定所有方法都保持负收益 |

在8个版本统一的三点诊断中，Cactus为8/8改善，区间为−0.28178%～−0.03928%；BQTerrace为4/8改善、4/8退化，范围−0.09369%～+0.35378%；MarketPlace仅1/8改善。以上是已观测频数，不能转成新算法100%或50%的成功概率。

Cactus的实测负号较稳定，但收益幅度能从约−0.19%退到约−0.04%；因此它不仅是“容易过”的序列，更是检查现有收益有没有丢失的关键。

BQTerrace不能因为R10-3当前三点有收益就跳过。R11-2的CE与R10-3接近，但其BQTerrace同区间从R10-3的−0.09369%变成+0.17766%，Cactus从−0.18905%减弱为−0.03928%。这说明只盯MarketPlace/BasketballDrive无法防止正向收益来源被破坏。

R6-2完整B平均为−0.05351%，其中MarketPlace、BasketballDrive改善，但BQTerrace退化；R3-1完整B为−0.05065%，则主要依靠Cactus、BQTerrace和RitualDance补偿其它序列。达到−0.04%不要求每条都改善，也不存在已证明可以同时拿到各版本逐序列最优值的规则。

## 4. CE与B相关性：可筛查线索，不可代替测试

相关单位是一套算法版本，横轴是CE序列的四点BD，纵轴是B序列的统一三点诊断BD。

| CE特征—B响应 | 全8版本Pearson | 排除固定预测器后的6版本 | 解读 |
|---|---:|---:|---|
| BQMall—BQTerrace | +0.6905 | +0.7289 | 有同向线索，但全8版本Spearman只有+0.4048，不能做定量外推 |
| PartyScene—BQTerrace | +0.3103 | +0.2509 | 不支持把PartyScene改善当成BQTerrace改善保证 |
| PartyScene—Cactus | +0.3136 | +0.4483 | 较弱且删组敏感，不足以预测新B收益 |
| FourPeople—MarketPlace | +0.0895 | +0.9880 | 极强的算法集合依赖，不能把局部高相关当普遍规律 |
| Johnny—MarketPlace | −0.8797 | −0.9567 | 历史上存在权衡线索，不能推成内容因果规律 |
| CE均值—B五序列三点均值 | −0.6243 | −0.6585 | CE更好并不保证B更好；排除因果选择方法族后变为+0.1535 |

负BD为改善，所以正相关代表两项通常同向，负相关代表在该样本集合上有一定交换关系。对所有关系的探索存在多重比较和开发集选择问题，没有作显著性或预测概率认证。

最有警示性的例子是FourPeople—MarketPlace：只看R3/R6/R9/R10/R11的6组时r≈0.988，但加入两组已存在的固定方法后r≈0.090。删一版本未必能暴露这种整类方法的分布变化，所以高相关不能用来给R12填B结果。

只用CE均值线性预测B三点均值，8版本留一验证平均绝对误差约0.0573个百分点；不看CE、仅预测训练集B均值的误差约0.0575个百分点。该检查已经很弱且方法之间不独立，但仍显示几乎没有实用预测优势。去掉R3-2后，局部5版本线性预测甚至差于均值基线。

因此，可作如下有限预估：

1. Cactus较有希望保持负号，但不能据此保证仍有−0.20%的幅度。
2. BQTerrace是有收益潜力但不稳定的重点测试对象；BQMall指标可以作附加观察，不能用作跳测依据。
3. MarketPlace有较大回收损失空间，却不是目前最有把握出现负收益的序列。R6-2证明存在可实现改善版本，但不能从其CE行为直接推导R12也能继承。
4. R12-11的PartyScene明显改善，并不构成Cactus或BQTerrace将改善的可靠证据；它的E原始点全部与R10-3相同，也不证明MarketPlace/BasketballDrive会被修复。

## 5. 将−0.04%的目标转成预算

```math
BD_B=\frac{b_{\mathrm{Cactus}}+b_{\mathrm{BQTerrace}}+b_{\mathrm{MarketPlace}}+b_{\mathrm{BasketballDrive}}+b_{\mathrm{RitualDance}}}{5}.
```

目标是五项和≤−0.20个百分点。CE保持R10-3或R12-11时，B=−0.04%分别对应完整BCE约−0.10770%和−0.11024%。这些是给定条件下的加权算术，不是新算法结果。

### 5.1 当前R10-3基线的精确剩余条件

四条完整B序列之和为−0.06955331个百分点。因此只补BQTerrace时，要使R10-3达到完整B≤−0.04%，其最终**四点曲线**必须满足：

```math
b_{\mathrm{BQTerrace}}\le-0.13044669\%.
```

这比之前“BCE≤−0.10%”对应的BQTerrace条件−0.03807%严格得多，原因是目标从整体BCE改成了B本身≤−0.04%。它不是QP22单点的码率要求。已测三点−0.09369%不能替代这条四点曲线，也不是其上界或下界。

### 5.2 新候选三条先测序列的预算示例

暂作资源规划假设：BasketballDrive、RitualDance保持R10-3当前四点结果，两者之和约+0.00652075个百分点。于是前三条需要：

```math
b_{\mathrm{Cactus}}+b_{\mathrm{BQTerrace}}+b_{\mathrm{MarketPlace}}\le-0.20652075\%.
```

若Cactus保住约−0.206515%、BQTerrace最终四点为假设的−0.10%，则MarketPlace只需≤约+0.1000%，不必强求它本身立刻变成负值。相对当前+0.13044%，减少约0.03045个百分点，就可能补足目标所需差距。

这只是条件化预算，绝不能把旧版后两条值借给新候选作为正式结果。三个三点诊断也不能直接代入这套四点预算认证达标。

## 6. 可执行测试顺序

- 候选数量：优先R12-11；预算允许时加R12-3，或在R12-4/6中择一作为不同机制对照。此顺序基于已知CE和机制信息，不是相关模型已经预测B胜率。
- 基线：补R10-3的BQTerrace QP22一个点，保留原二进制/规格身份。
- 新候选首轮：Cactus、BQTerrace、MarketPlace各QP27/32/37，共9点。若只能先跑6点，Cactus＋MarketPlace，随后补BQTerrace。
- 达到CE资源门槛仅代表值得测B；三点诊断用于识别大幅退化、方向和身份异常，不视为正式四点B，也不用小波动直接永久淘汰机制。BQTerrace三点和四点形状可能差异较大，临界候选需补QP22再判断。
- 少数值得保留的候选：补上述三条QP22，再补BasketballDrive和RitualDance的四QP，共11点，形成20点完整B。
- 对首轮三条的结果同时看绝对改善和直接对R10-3的差异。Cactus或BQTerrace仍为负但明显丢失幅度，也可能使B平均无法达到−0.04%；MarketPlace小幅为正不一定意味着整体无望。

测试子集不按“只挑负收益”决定；它是有意选择的高信息量集合，不代表全部Class B分布。
