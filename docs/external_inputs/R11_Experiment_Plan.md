# R11 实验设计：保留局部因果收益，修复跨内容失效

## 1. 状态、依据与边界

这是新的实验规格，尚未修改或运行编码器。依据快照：`e1413fd0bf361cdea7d06fbc1b3a78c7036de5de`，分支 `experiment/ts-predictor-study`。R9/R10编号、源码和结果保持不变。

R10-3 的 CE 为 −0.15605%，C/E 为 −0.18278%/−0.12042%；R9-9 的 B 在五序列 QP27/32/37 纯实测共同区间为 +0.12165%（相对R3为+0.16941%）。后一项不是完整四点CTC，但已经足以把跨内容稳定性纳入下一轮。R10-3 的 B 尚未实测，不能从CE结果推断已修复B。

核心方向不是统一增强guard，而是分清：没有验证证据、证据覆盖受CG边界限制、评价上下文与当前目标不一致、专家池遗漏简单动作。上述都是待检验假说，不把B/高分辨率预先等同于稀疏或低幅值。相关详细分析见 `R10_Results_and_R9_B_Analysis.md`。

**共同基线为 R10-3，不是 R9-9。** 除明示项外，全YUV、原TS支持尺寸、原scan、BDPCM/pure-bypass不映射方式、lambda、量化搜索和CG入口概率冻结均不变。无额外模式比特不等于旧decoder兼容；新增规则须两端一致。

## 2. 共同数学与工程定义

### 2.1 专家、动作和验证集

令当前scan位置为i，五个因果幅值为 `h_i=(L,U,D,LL,UU)`，保留真实可得性。未量化残差、当前目标幅值和未来系数不参与公共选择。

专家A=R8-12（fractional、P0、identity-trim、Smax），B=整数Raw R2-2，C=整数Current-guard R3-1。三者都是不递归调用选择器的纯函数。全部基础动作k=0；p=0/1规范化为同一identity。

原验证集 V0(i) 是当前位置五邻域中：同CG、真实存在、非零、scan(j)<scan(i) 的历史目标。顺序固定L/U/D/LL/UU。

对每个j，先从j自己的更早邻域h_j产生 p_e(h_j;s_i)，之后才用已知幅值a_j评分。s_i为当前CG入口冻结快照；A必须保留CF依赖，不能因为验证是整数就关闭快照。Rice/动态范围沿用当前context定义。

$$\ell^I_{e,j}=C_I(M_0(a_j,p_e(h_j;s_i))).$$

原CF验证为

$$\ell^{F,old}_{e,j}=C_F(M_0(a_j,p_e(h_j;s_i));s_i,d(h_j)),$$

其中d(h)是L/U非零数，固定cutoff=10。CI统一左移到与CF相同的定点单位；累加至少64位。

### 2.2 R10-3选择规则

先最小化 `L_I(e)=sum_j ellI(e,j)`；仅在其最小集合内最小化 `L_F(e)`；最后固定A→B→C。当前完整动作全部相同则直接返回该动作；验证集为空默认A。更换验证集时，各专家必须在同一验证集上评价。

这里的L不是实际完整CABAC字节，更不是闭环D+lambdaR。编码端RDOQ的输入快照可以不同于最终Writer，两者不强行假设相同，但最终Writer/Reader必须同步。

### 2.3 “无证据”的精确定义

$$n_{eff}(i)=\#\{j\in V_i:\exists e,f,\ M_0(a_j,p_e(h_j;s_i))\ne M_0(a_j,p_f(h_j;s_i))\}.$$

它统计历史目标在专家间是否产生不同**映射幅值**，不是当前有几个不同p，也不是整数代价是否偶然相等。整数损失相同但映射不同仍可能含信息，应保留CF平局处理。

## 4. R11-1：没有区分证据时使用R3，不统一压制切换

先计算当前A/B/C完整动作。如果全部相同，保持原快捷返回。否则构造V0及n_eff：

- n_eff=0：返回当前h_i下专家C的动作；
- n_eff>0：完全保持R10-3的CI→CF→固定tie。

空V0也属于n_eff=0。不增加n_eff≥2/4的门槛，不因仅一个有效样本就拒绝选择。不把数值平局误当作结构性无证据。

这里R3是一个已有完整B对照的回退候选，不是已证明处处最优或原生Current。该组局部变化严格限于缺乏区分证据的位置，其它固定状态的决定不变；闭环中后继状态仍会分叉。它可能减少A默认偏置，也可能损失A的先验优势，必须同时看B/C/E。

## 5. R11-2：保持整数主排序，只重新定位CF平局的评价上下文

V0、专家池、CI损失和最终tie顺序不变。只有CI存在多个最小专家时，改用

$$\ell^{F,query}_{e,j}=C_F(M_0(a_j,p_e(h_j;s_i));s_i,d(h_i)).$$

原规则用d(h_j)，新规则用当前目标的d(h_i)。当前h_i是已解码邻域，并没有读取a_i；快照仍为同一CG入口，不读即时Reader上下文，不使用当前事后cutoff。

**只改变验证loss的分类，不能把历史专家自身产生动作时使用的h_j分类也改掉。** 该设计类似把历史预测误差在当前编码代价下重评，不声称更精确地还原历史真实比特。

唯一CI赢家必保持不变；只有真正CI平局位置有机会改变。所有历史分类等于当前分类时也应逐动作一致。空验证集继续A，避免同时混入R11-1。风险是当前分类也不适合历史误差分布，因此与R10-3完整配对。

## 6. R11-3：同CG扩大局部验证，不改成全前缀历史

构造V3：先原样保留V0及其顺序，然后在当前位置曼哈顿距离1～3的24个几何偏移中枚举候选：

1. 必须真实存在于当前TU；
2. 必须原生scan(j)<scan(i)，在读取其幅值之前先检查此条件；
3. 必须同CG、幅值非零、尚未进入V0；
4. 按(曼哈顿距离升序、scan(j)降序、y升序、x升序)排序，最多补至8个。

保持原CI与CF_j验证、同一专家池和tie。没有新增专家，不按幅值大小挑选目标，也不做全CG前缀累计。8和半径3是本轮预设计算预算，不是按CE调出的最佳参数。

本组回答“局部证据太少”是否重要。更多样本不等于独立样本，也可能跨越结构边界；若真实target regret变差，应记录而不是继续任意扩大窗口。

## 7. R11-4：在3的基础上测试CG边界限制

先构造完整V3。若不足8，再从同一半径内加入属于**更早CG**、同TU、scan更早、真实存在且非零的位置；排序与3相同，补至8为止。保证V3是V4的有序前缀，不挤掉原有同CG样本。

历史目标j及h_j都可来自同TU已恢复位置；不读其它TU、CTU、帧或未来参考。必须在所有参与调用路径上验证可得性，不能把当前CG第一二遍的临时mapped level当作原幅值。

**统一在当前CG快照s_i上重算历史专家和损失**，不需要保存旧CG的真实概率状态，也不声称重算历史实际编码率。这保留条件验证的含义，同时改变样本覆盖；与R11-3形成明确配对。

没有跨TU持久学习状态。缓存须包含当前CG快照/专家池/完整support，原仅能索引当前CG的缓存不能越界拿来保存更早CG目标；可用容量8～24的局部缓存或不缓存首次实现。CG/快照/候选q/分支变化必须安全失效。

## 8. R11-5、6：给选择器补入简单动作，不强制回退

R11-5新增 D_N(h)=canonical(max(L,U),k=0)。R11-6独立新增 D_0(h)=identity(0,0)。两组都保留A/B/C，不替换原专家。

当前位置和每个历史验证目标都必须生成对应D，使用同一个V0以及原CI→CF_j规则。最终tie A→B→C→D；空集仍A。快捷返回必须检查全部四个动作，不能只看旧A/B/C已相同就跳过新D。

R3并不始终等于Current，A也并不始终等于NoPred，因此增加D可能开放原池没有的动作。D与某个专家在当前h_i相同，不代表二者在历史h_j都相同，不能只按当前p合并全部专家验证。可以共享损失/动作计算，但必须保持各策略身份及tie语义。

这不同于早期“未接受就NoPred”：新动作必须接受因果验证竞争，不无条件替代现有赢家。其新增提案成本小于再加入一套完整搜索专家，但验证列增加；真实编码速度仍需测量。

## 9. 两个预设组合

- R11-7：V0、A/B/C不变；无证据回R3（1），有证据时CI优先＋CF_query平局（2）。
- R11-8：V4、A/B/C、原CF_j；在扩展验证集计算n_eff，无证据回R3（1），有证据保持原字典序。

07的四角是基线/1/2/7；08的四角是基线/1/4/8。两组均不包含新增D。不将单组BD-rate相加预测组合结果；比较交互须在四条曲线共同质量域上进行。

## 10. 实验安排：先CE筛选，再分级进入Class B

### 10.1 先用最终BCE目标反推是否值得测试B

最终LB BCE按12条序列等权：

[
BD_{BCE}=rac{7BD_{CE}+5BD_B}{12}.
]

若目标是

[
BD_{BCE}le -0.10%,
]

则给定CE结果后，Class B至少需要达到

[
oxed{
BD_B^{req}=rac{-1.20-7BD_{CE}}{5}
}
]

（上式各数值单位均为百分点，例如 `BD_CE=-0.15` 代入 `-0.15`）。

历史完整LB B结果中，当前台账里较好的平均值约为：
- R6-2：−0.05351%；
- R3-1：−0.05065%；
- Fixed-Directional：−0.03443%；
- Fixed-NoPred：−0.02068%。

因此，若假设下一方案的B平均只能达到目前已经观测到的最好量级约−0.0535%，反推CE至少约为−0.1332%才能让BCE达到−0.10%。这不是数学不可突破的理论上界，新算法可以超过历史最好值；它只是资源分配的经验可行性边界。

本轮固定一个更保守、便于执行的**实际B测试门槛**：

[
oxed{BD_{CE}le -0.14%}
]

才进入Class B诊断。若CE > −0.14%，默认不测试B，除非该实验本身明确专门针对B失效机制且有独立局部证据；这种例外必须在启动前说明，不能在结果出来后追测。

对应目标关系：

| CE平均 | 为使BCE达到−0.10%，所需B平均 |
|---:|---:|
| −0.18% | ≤ +0.012% |
| −0.17% | ≤ −0.002% |
| −0.16% | ≤ −0.016% |
| R10-3：−0.15605% | ≤ −0.0215% |
| −0.15% | ≤ −0.030% |
| −0.14% | ≤ −0.044% |
| −0.1332% | ≈ −0.0535% |
| −0.13% | ≤ −0.058% |
| −0.12% | ≤ −0.072% |

所以CE在−0.14%附近时，B已经需要接近R3/R6-2历史最好量级；CE只有−0.12%～−0.13%时，再花大量资源跑完整B通常缺乏性价比。相反，CE达到−0.16%附近后，只要B轻微改善即可实现整体−0.10%的目标，此时B测试价值明显增加。

### 10.2 Class B只先跑三个“哨兵序列”

通过CE门槛的候选，不立即跑完整5序列×4QP。先跑：

- **MarketPlace**：R9-9在QP27/32/37实测公共区间退化最明显，用于快速发现跨内容失效；
- **BQTerrace**：R3完整四点明显改善，而R9-9三点区间退化，能区分“原guard有效而新选择器失效”的情况；
- **Cactus**：R3和R9-9都存在改善，用作正向控制，检查为了修复B退化是否反而损伤本来可获益的B内容。

三条序列先只跑 **QP27/32/37**，每个候选9个任务。QP22不用于首轮筛选。这个三点结果只是公共质量区间诊断，不登记为正式四点CTC B平均。

暂不首轮跑：
- BasketballDrive：R3与R9-9都没有表现出稳定强收益，首轮区分度较低；
- RitualDance：当前退化/收益幅度较小，优先级低于上述三条。

它们仍属于最终完整B测试的一部分，不是永久删除。

### 10.3 B哨兵只用于早停，不用它直接估计完整B平均

哨兵集合是故意选择的高信息量内容，不要求代表完整Class B分布。因此不把三序列均值直接代入BCE公式，也不从它们外推正式B平均。

固定早停原则：
1. 若MarketPlace或BQTerrace仍出现明显的大幅正增量，或Cactus由既有负收益翻成明显正增量，则优先停止该候选的完整B测试；
2. 若三条均未暴露明显失效，再结合该候选CE值计算 `BD_B^req`，判断完整B达到目标是否现实；
3. 只有仍具有实现BCE≤−0.10%的现实可能时，才补齐完整Class B。

这里“明显失效”主要用于资源调度，不作为论文统计阈值。首轮不预注册一个很细的+0.03/+0.05参数去反复追边界；重点看方向、幅度、同QP rate/PSNR支配关系和三点曲线是否稳定。若结果接近0，再补点而不是用小阈值硬判。

### 10.4 完整B只给最终少数候选

通过哨兵筛查后，补齐：
- MarketPlace/BQTerrace/Cactus 的QP22：3点；
- BasketballDrive、RitualDance 的4QP：8点。

因此每个已做哨兵的候选只再需要11点即可得到完整20点Class B。

R10-3作为R11共同基础也采用相同资源策略：
- 先只补MarketPlace/BQTerrace/Cactus × QP27/32/37 共9点；
- 只有确有必要比较最终BCE时，再补剩余11点；
- 不再预先要求完整20点B作为所有R11启动前置条件。

R9-9已有B数据继续作为失效对照；其缺失QP22可在最终需要正式四点比较时再补，不因R11首轮自动补齐。

### 10.6 首批优先级

CE先完整跑全部8组，避免根据短测过早删机制。

1. 首先保留 `CE<=-0.14%` 的配置；
2. 若多个候选满足，优先CE更强、对R10-3直接增量更稳、且机制信息互补的候选进入B哨兵；

4. 只有在其目标层面统计明确显示B失效机制被针对时，才允许预先声明的例外B测试。

这样B成为**候选确认阶段**而不是每轮探索阶段，符合最终BCE≈−0.10%的目标和当前资源约束。


## 11. 结果和特征统计

每组报告Current、R10-3、直接机制基础、R9-9/R3的对应比较；独立报告B/C/E与12序列BCE，不以CE收益掩盖B退化。保留B三点同覆盖诊断、所有同QP的率/PSNR变化和插值敏感性，不把单点rate当BD。

需要最终Writer人口的以下计数：V0/V3/V4大小、n_eff、空集/结构性无证据比例；CG边界与几何补入数量；当前expert distinct；CI严格赢家/数值平局/结构性平局；默认A/C、D选择；新旧完整动作及实际remap变化；最终量化/TU获选。

事后目标层面输出每专家CI、CF10、实际路径CF损失与selected target regret；同时标注n/n1/d、CU模式、尺寸、CG位置、组件和配置。当前真实幅值/最终cutoff只在结果确定后用于观察，不进入公共策略。验证集selected regret按定义很可能为0，不能当泛化质量。

特别区分：A默认造成的损失、一个有效样本造成的错误切换、已有池没有正确动作、扩样本后反而失配。至少在R3、R9-9、R10-3的不同冻结轨迹上做短测观察，避免只在赢家自己的量化分布上评价。

## 12. 实现与正确性门槛

- 正式R11代码与R10模式互斥，旧模式输出不变；新增简单整数MODE=1..8，运行名与本表对应。不能偷偷重定义R10-3。
- 复用纯专家和loss matrix，扩大数组容量到最多8行/4列；合计和与乘法64位，范围和去重明确，native扫描尺寸动态取得，不硬编码CG=16。
- Writer多遍、Reader第三遍、RDOQ和最终replay使用同一因果规则；跨CG历史是已恢复量化幅值，不是尚未逆映射的临时系数。
- R11-2的唯一CI赢家、相同分类场景应与基线一致；R11-1/7/8仅相应n_eff=0改变回退；R11-3/4有序嵌套，当前/未来污染不改变V或所选动作。
- 5/6测试三旧专家一致但D不同的状态；测试历史动作不同而当前动作相同的策略，避免错误合并。
- 检查矩形TU、边界/缺失邻居、全零CG、重复幅值、0/1规范化、Rice/动态范围、bypass/BDPCM、q编辑、CG清零、RDO分支复制回滚和解码hash。
- 统计关闭后同机配对计时。局部预算V≤8使渐近复杂度仍O(N)，但常数可能增加，不声称线性就便宜。不能为加速把局部V换成累计全前缀。

## 13. 当前已验证与未验证

`r11_reference.py`提供选择器和几何集合的数学参考，已运行10,000个合成选择案例、6,528项几何检查。验证包括唯一CI赢家不变、无证据回退、同CG/同TU嵌套及未来幅值污染不变性。扫描构造仅为测试用分组对角顺序，不冒充原生参考软件scan规范。

未实现完整R11专家/codec补丁，未运行新视频、原生CABAC、真实状态分布或复杂度评测。固定的8、半径3和无证据回R3均是待验证设计，不是从当前结果证明的最优值。
